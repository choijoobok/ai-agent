# user-guide/ — 사람이 읽는 안내

> **여기는 *따라할 절차* 다.** *지켜야 할 규칙* 은 [`aidd-guide/`](../aidd-guide/INDEX.md) 가
> 갖고, *만들어진 산출물* 은 [`documents/`](../documents/INDEX.md) 가 갖는다.
>
> **같은 사실을 두 곳에 적지 않는다**(CLAUDE.md §4-3). 규칙을 알아야 하는 자리에서는
> 요약하지 않고 **링크만** 둔다 — 요약을 옮겨 적으면 그 순간부터 두 사실이 되고, 갈렸을 때
> 어느 쪽이 참인지 알 방법이 없다.

| 하려는 것 | 읽을 것 |

| **개발 환경을 만들고 싶다** | [02-setup.md](02-setup.md) — 필요한 것 · 받는 순서 · 띄우는 법 · 막힐 자리 |
| **화면·기능을 하나 만들고 싶다** | [03-develop.md](03-develop.md) — 요건서부터 게이트 초록까지 |
| **빌드하고 배포하고 싶다** | [04-release.md](04-release.md) — 단일 JAR · 프로파일 · CI |
| **운영 중에 무엇을 봐야 하나** | [05-operate.md](05-operate.md) — 지표 · 이력 · 장애 · 고객사 협의 항목 |
| **AI 가 쓴 기호·약자가 무슨 뜻인지 모르겠다** | [06-glossary.md](06-glossary.md) — 문서 ID 접두 · 단계와 게이트 · 우리가 정해 쓰는 말 · IT 약자 |
| **지금 훅과 스킬이 뭐가 있나** | [07-harness.md](07-harness.md) — 걸린 훅과 강도 · 스킬 목록. **생성물이라 항상 실물과 같다** |

## 처음 온 사람이 읽는 순서

```
① 저장소 README            무엇을 만드는 프로젝트인가 (5분)
② 01-project.md            어떻게 굴러가는가 · 내 역할은 무엇인가 (15분)
③ 02-setup.md              환경을 만든다 (실습 30분~2시간)
④ CLAUDE.md                AI 가 매 세션 읽는 헌법 — 사람도 한 번은 읽는다 (20분)
⑤ aidd-guide/INDEX.md      규칙이 어디 있는지의 지도 — 통독하지 않는다

곁에 두고 필요할 때 편다
   06-glossary.md          기호·약자 사전 — 통독하지 않는다. 모르는 말을 만났을 때 찾는다
```

- **④를 건너뛰지 않는다.** AI 가 무엇을 지키도록 되어 있는지 모르면, AI 의 결과물이
  *왜 그렇게 나왔나* 를 판단할 수 없다. 특히 §4(문서 예산)과 §5(절대 규칙)는 사람이 알고
  있어야 AI 의 차단 메시지가 이해된다.
- **⑤는 통독하지 않는다.** 26,000줄이다. INDEX 의 결정 트리만 익혀 두고 필요할 때 들어간다.

## 이 프로젝트에서 사람이 하는 일

**AI 가 PM·BA·AA·DBA·개발자·테스터를 겸임하고 사용자는 고객이자 의사결정자다.** 그래서
사람이 하는 일이 전통적인 개발 프로젝트와 다르다.

| 사람이 한다 | AI 가 한다 |
|---|---|
| **결정** — 되돌리기 비용이 큰 선택 (스택·인증·데이터 모델·범위) | 선택지와 권장안을 만들어 제시한다 |
| **게이트 승인** — 단계를 넘길지 판단 | Exit Criteria 자체검증 · 레드팀 자기반박 후 승인 요청 |
| **화면 승인** — 요건서와 목업을 함께 보고 판단 | 요건서·목업을 만들고 승인 없이 코드를 쓰지 않는다 |
| **직접 테스트** — 실제로 써 본다 | 게이트를 초록으로 만든다 |
| **범위 판정** — 변경 요청의 3옵션 중 하나 선택 | 영향 분석과 재작업 규모를 산정해 3옵션 제시 |

> **AI 의 게이트 초록이 사람의 테스트를 갈음하지 않는다** — *돌아간 것* 과 *쓸 만한 것* 은
> 다르다(CLAUDE.md §6.3 ⑤).

## 폐쇄망에서 사람이 직접 코딩해야 할 때

**AI 를 쓸 수 없는 환경이 실재한다.** 그때 필요한 것은 *짧고 공통화된 소스* 와
*읽을 수 있는 문서* 다 — 그래서 이 프로젝트는 그 둘을 기능보다 앞에 둔다.

- 개발 표준은 [`aidd-guide/standard/INDEX.md`](../aidd-guide/standard/INDEX.md) 가 갖는다.
  **AI 를 위해 쓴 문서지만 사람이 읽을 수 있게 쓰여 있다** — 문맥 비용과 이해 비용을 줄이는
  방법이 같기 때문이다.
- 레시피는 [`aidd-guide/playbook/INDEX.md`](../aidd-guide/playbook/INDEX.md) — CRUD·마스터디테일·
  엑셀·모달·트리 화면을 만드는 순서가 실물 샘플과 짝지어 있다.
- **표준을 추정해 새로 만들지 않는다.** 문서에 없으면
  `sources/frontend/src/features/sample/` 의 샘플 여섯을 읽는다 — 그 목적으로 있다.
