# 01. 프로젝트 수행 방법

> **규칙의 정본은 [`aidd-guide/process/`](../aidd-guide/process/overview.md) 다.** 여기는
> *그것이 실제로 어떻게 굴러가는지* 를 사람의 말로 옮긴 것이다.

## 1. 한 문장으로

**사용자는 요청하고 결정한다. AI 는 분석·설계·개발·테스트의 모든 산출물을 만든다.**
그 사이를 **게이트**가 끊어 놓아, AI 가 승인 없이 다음 단계로 넘어가지 못한다.

## 2. 왜 이런 방식인가

전통 방법론의 전제가 AI 시대에 바뀌었다.

| 전통의 전제 | 지금의 실제 | 이 프로젝트의 대응 |
|---|---|---|
| 문서 작성 비용이 크다 → 줄이자(애자일) | 비용 ≈ 0 | **문서는 폭포수처럼 두껍게.** AI 에게 문서는 장기 기억이다 |
| 재작업이 비싸다 → 앞단을 두껍게(폭포수) | 코드 재작업은 싸졌다 | **리듬은 애자일처럼.** 수직 슬라이스로 짧게 돈다 |
| 병목은 개발 속도 | 병목은 **사용자 의사결정 대역폭**과 **AI 의 맥락 유실·과속** | 질문 예산 · 게이트 · 추적성 · 레드팀 |

**다만 "문서를 두껍게" 가 "문서를 많이" 는 아니다.** 이 프로젝트는 세 저장소를 합쳐 만들었고,
셋이 공통으로 앓던 병이 *문서를 정리하면 정리 내역을 적는 문서가 생기는 것* 이었다.
그래서 **문서 예산**을 기계로 강제한다 — [§6](#6-문서-예산--왜-차단당하는가).

## 3. 단계와 게이트

```
P0 착수 ─▶ P1 발견 ─▶ P2 아키텍처 ─▶ P3 설계 ══▶ P4 구현 ─▶ P5 검증 ─▶ P6 인도
                                       ★동결★    (슬라이스 반복)

각 단계 끝: Exit Criteria 자체검증 → 레드팀 자기반박 → 사용자 승인 → 다음 단계
상시:      ADR·가정 원장 / 추적성 / 변경관리 / project.state.yaml
```

| 단계 | 무엇을 정하나 | 사용자가 승인할 것 |
|---|---|---|
| **P0 착수** | 목적·범위·성공 기준·액터·제약 | **범위와 성공 기준.** 여기가 흔들리면 뒤의 모든 우선순위가 흔들린다 |
| **P1 발견** | 용어·업무 프로세스·요구사항 | **업무 프로세스와 요구사항 우선순위** |
| **P2 아키텍처** | 스택·인프라·비기능 목표·권한 모델 | **되돌릴 수 없는 결정들.** ADR 로 남는다 |
| **P3 설계** | 유즈케이스·기능·데이터 모델·API·화면·TC | **★베이스라인 동결★** — 이후 변경은 CR 절차 |
| **P4 구현** | 수직 슬라이스 반복 | 화면별 요건서·목업 (슬라이스마다) |
| **P5 검증** | 시나리오·비기능·결함 | **잔여 결함의 수용 수준** |
| **P6 인도** | 배포·런북·매뉴얼·인수 | **인수** |

- **한 턴에 하나의 게이트만 넘는다.** "설계도 하고 구현도 했습니다" 는 금지다.
- **G3(P3 설계) 승인 전에는 `sources/` 에 코드를 쓸 수 없다** — 훅이 차단한다.
  템플릿 자체의 보수는 예외이며, 그때는 `documents/project.state.yaml` 의
  `template_maintenance: true` 를 켠다(켠 사실이 상태 파일에 남는다).

### 제품 로드맵과 개발 단계는 다른 축이다

`documents/spec/00-charter.yaml` 의 로드맵은 **P1 조회 → P2 실행 → P3 자동화 → P4 개인화** 로
제품 출시 단계를 말한다. 위의 **P0~P6 은 개발 단계**다. **로드맵 P1 하나를 만들기 위해
개발 P0~P6 을 한 바퀴 돈다.** 헷갈리면 `project.state.yaml` 의 `current.phase` 를 본다 —
그것은 항상 개발 단계다.

## 4. 지금 어디까지 왔는지 보기

```bash
node .claude/hooks/trace-check.mjs --all
```

또는 Claude Code 에서 `/pm-status` — [`documents/project.state.yaml`](../documents/project.state.yaml)
을 읽어 단계·게이트·미결 질문·다음 할 일을 한 화면에 보여준다.

> **현재 상태는 그 파일 하나가 갖는다.** 현황을 적는 다른 문서를 만들지 않는다.

**지금 이 프로젝트는 P0 이고 게이트 넷이 `in_progress` 인 이상 상태다** — 설계가 먼저
있었고 프로세스를 뒤에 씌웠기 때문이다. 정상화 방법은 하나다: **P0 부터 `/phase-gate` 를
돌려 순서대로 승인받는다.**

## 5. 사용자가 답할 것 — 질문 규약

AI 는 질문을 **배치로 묶어** 낸다. 규약이 있어 사용자의 시간을 아낀다.

- 한 번에 **최대 7개**.
- 모든 질문에 **권장안(기본값)** 이 붙는다 — "기본값으로" 한 마디면 즉시 진행된다.
- `[필수]` 는 **되돌리기 비용이 큰 것만**이고 **3개 이하**다.
- 각 질문에 **영향 범위**(이 답이 바뀌면 무엇이 다시 만들어지나)가 한 줄로 붙는다.
- 답이 없으면 AI 는 멈추지 않고 **`ASM-###` 으로 가정하고 진행**한다. 단 **다음 게이트
  전에 반드시 확인받는다** — 기한 게이트에서 미확인 가정이 있으면 게이트가 열리지 않는다.

### 이해하지 못한 승인을 받아내지 않는다

게이트마다 AI 는 **결정 카드**(업무 언어 3~5줄)와 **역질문**(AI 가 확신 없는 것 1~2개)을
함께 낸다. 그리고 **침묵 승인**을 센다 — 질문·반박·역질문에 답하지 않고 통과시킨 게이트가
연속되면 그것을 보고한다.

> **"절차를 줄이자" 에 AI 는 즉흥적으로 답하지 않는다.** 줄일 수 있는 것 / 절대 안 되는 것 /
> 지금은 빠르지만 나중에 비싼 것, **3분류로 답한다**.

## 6. 문서 예산 — 왜 차단당하는가

`documents/` 에 새 문서를 만들면 **훅이 막을 수 있다.**

```
documents/정리내역.md 는 산출물 지도에 없는 자리다 — 새 문서를 만들 수 없다.
```

**의도된 동작이다.** 만들 수 있는 자리는
[`aidd-guide/artifact/INDEX.md`](../aidd-guide/artifact/INDEX.md) 의 **산출물 지도 40행**이
정하고, 훅이 그 파일을 읽어 판정한다.

정말 새 종류가 필요하면 **지도에 행을 먼저 더한다.** 번거롭게 느껴지는 것이 이 규칙의
핵심이다 — 그 번거로움이 없으면 문서가 다시 늘어난다.

- **정리·현황·근거를 적는 별도 문서를 만들지 않는다.** 무엇을 왜 그렇게 했는가는 **커밋
  메시지**가 갖고, 되돌리기 비용이 큰 것만 **ADR** 이 갖는다.
- **차단이 잘못 걸린다고 느껴지면 훅을 끄지 말고 말한다.** 강도가 안 맞으면 규칙을 고친다 —
  꺼진 훅은 없는 훅이다.

## 7. 변경이 필요할 때 (G3 이후)

**설계 베이스라인 동결 이후의 변경은 CR 절차를 탄다.**

1. AI 가 **영향 분석**을 낸다 — 직접 영향(반드시 수정) / 간접 영향(검토 필요) / 예상 재작업.
2. AI 가 **3옵션**을 제시한다. **항상 "안 함" 이 포함된다.**
   - **A** 지금 반영 (재작업 규모와 함께)
   - **B** 나중에 (백로그로)
   - **C** 안 함 (그 대가와 함께)
3. **사용자가 판정한다.** 판정이 `documents/decisions/CHANGES.md` 에 남는다.
4. AI 가 **범위 증가율**을 보고한다 — 요청을 다 받아들여 범위가 폭발하는 것을 막는 장치다.

> **문구·정렬처럼 요건이 바뀌지 않는 것은 CR 이 아니다** — 바로 고친다.

## 8. 세션이 바뀌어도 일관되게

**AI 는 세션이 바뀌면 맥락을 잃는다.** 그것을 막는 장치가 넷이다.

| 장치 | 무엇을 지키나 |
|---|---|
| [`documents/project.state.yaml`](../documents/project.state.yaml) | *지금 어디인가* — 세션 시작에 훅이 문맥에 넣는다 |
| **추적성 체인** (`REQ → UC → FEAT → ENT/API/SCR → TC`) | *이 코드가 왜 여기 있나* — AI 의 외장 기억 |
| [`CLAUDE.md`](../CLAUDE.md) | *무엇을 해야 하나* — 매 세션 반드시 읽힌다 |
| **훅 열하나** | 규칙을 잊어도 기계가 막는다 |

**누가 언제 어디서 작업해도 같은 판단이 나오는 근거가 이 넷이다.** 그래서 이 넷을 손대는
것은 헌법 수준의 결정이며 ADR 로 남긴다.
