# 가정 원장 (Assumption Ledger)

사용자 답변을 기다리다 멈추지 않기 위한 장치. **진행하되 흔적을 남긴다.**

규칙 → `aidd-guide/process/06-decision.md` §3
- 가정으로 만든 산출물 안에는 `[ASM-###]` 을 인라인 표시한다.
- 각 가정에는 **확인 기한(게이트)** 을 붙인다. 기한 게이트에서 미확인 가정이 있으면 게이트가 열리지 않는다.
- 확인되면 상태만 갱신한다. **행을 지우지 않는다** (이력 보존).
- 가정이 틀린 것으로 밝혀지면 즉시 변경 영향 분석 → CR.
