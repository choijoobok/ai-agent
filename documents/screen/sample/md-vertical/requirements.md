# 요건 정의서 — 샘플 · 마스터-디테일(상하)

## 개요

- **무엇을 하는 화면인가**: 샘플 주문(위)과 그 주문의 **품목**(아래)을 **각자 저장**하고, 출고 지시와 품목 금액 재계산을 실행한다.
- **프로세스상 위치**: 없음 — **어휘의 전시**다.
- **이 데이터를 누가 쓰나**: 샘플 여섯이 같은 두 테이블을 나눠 본다. **이 화면의 조회 경로를 좌우 분할·복수 탭 화면이 그대로 재사용한다.**
- **바꾸면 어디가 흔들리나**: 여기가 **유일한 실물**로 갖는 셋 — 상하 스플리터 · **마스터 삭제 게이트** · 조건부 편집 함수.

> **엑셀의 세 번째 갈래가 여기서만 실물이다.** *헤더 1건 + 상품 N건이고 화면은 상단과 하단으로 쪼개 보여주지만, 사용자는 헤더와 상품을 합친 엑셀 하나를 원한다* — **그 표는 화면에 없으므로 프론트가 만들 수 없다.**

> **이 문서는 구현된 소스에서 역으로 작성했다**(2026-09-03).

## 1. 화면 구성

```
[조회조건 — 넷. 마스터에만 있다]
[그리드 A: 주문 — 컬럼 아홉]   ⓐ [출고 지시]  ⓑ [품목 재계산]
[━━ 스플리터(상하) ━━]
[그리드 B: 품목]              ← 자기 저장 버튼을 갖는다
```

- **저장 단위가 둘이다.** 마스터와 디테일이 **각자 저장한다** — 저장 버튼이 그리드마다 따로이며, **묶으면 *품목만 고쳤는데 주문도 갱신됨* 이 되어 감사 컬럼이 거짓말을 한다.**
- **마스터 컬럼이 아홉이다.** 테이블에는 스물여섯이 있지만 나머지는 **그 어휘를 맡은 화면**이 그린다 — 여기서 전부 그리면 이 화면 하나가 어휘를 통째로 시연하게 되고, **그러면 *레이아웃* 이라는 이 화면의 주제가 묻힌다.**
- **디테일은 조회조건을 갖지 않는다** — 대상이 마스터의 선택이며 그것은 **구조**이지 *사용자가 좁힌 것* 이 아니다.

### 1-1. 마스터-디테일 연동

- 연동 기준: 마스터의 `ORD_ID` 로 품목을 조회한다.
- **미저장 신규 마스터 행**: 디테일이 잠긴다.
- **마스터 삭제 게이트가 여기서만 실물이다** — `itemCnt`(품목 수)를 마스터 응답이 갖고 있어 **행마다** 답할 수 있다. **행마다 물으면 왕복이 스물이다.**

## 5. 버튼 · 액션

| 버튼 | 액션 | 대상 | 진행률 |
|---|---|---|---|
| 조회 · 저장(마스터) · 저장(디테일) | `R` `S` | — | — |
| **ⓐ 출고 지시** | **`X`** | 고른 주문 | **없다** — 상태 하나를 바꾸는 일이라 **즉시 끝난다** |
| **ⓑ 품목 재계산** | **`X`** | 고른 주문 | **있다** — **행×디테일**이다 |

- **둘이 나란히 놓인 것이 요점이다.** 같은 `X`, 같은 *고른 행* 인데 **하나는 즉시 끝나고 하나는 고른 주문마다 딸린 품목 전건을 돈다** — 주문 하나가 수천 건일 수 있어 **창이 소제목으로 *지금 어느 주문* 을 말한다.**

### 5-1. 엑셀 — **세 갈래가 한 화면에 있다**

| 어디 | 무엇 | 누가 만드나 |
|---|---|---|
| 마스터 — 현재 페이지 | 주문 × 품목 **합본** | **서버**(`exportOrderPage`) |
| 마스터 — 전체 | 〃 | **서버**(`exportOrderAll`) — **상한 판정도 서버가 한다** |
| 마스터 — **품목 없는 주문** | **조회로는 낼 수 없는 표** | **서버**(`exportOrderNoItem`) |
| **디테일** | 품목 표 | **프론트** — 화면의 표와 같으므로 **서버로 돌릴 이유가 없다** |

- **아래 pane 의 엑셀이 프론트인 것이 대조점이다** — 왕복이 0 인 것을 왕복 하나로 만들 뿐이다.

## 7. API

| 용도 | 키 | 액션 |
|---|---|---|
| 마스터 목록 | `getOrderList` | R |
| 디테일 목록 | `getItemList` | R |
| 마스터 저장 | `saveOrders` | S |
| 디테일 저장 | `saveItems` | S |
| **출고 지시** | `shipOrders` | **X** |
| **품목 재계산** | `recalcItems` | **X** |
| 엑셀 셋 | `exportOrderPage` · `exportOrderAll` · `exportOrderNoItem` | **E** |

- **`getOrderList` · `getItemList` · `saveOrders` · `saveItems` 를 좌우 분할·복수 탭 화면이 그대로 선언한다** — **같은 URL 을 여러 화면이 선언하는 것이 정상이며**, 시드가 그 URL 을 여러 메뉴에 매핑한다. **적지 않으면 그 화면에서만 403 이 난다.**

| `S3-29` | **마스터** 조회로 디테일을 새로고침하려 한다 | **고른 행을 잃는다** — 마스터 조회는 디테일을 리셋하고 자동 선택도 하지 않는다. **그래서 디테일에 조회가 필요하다** |
