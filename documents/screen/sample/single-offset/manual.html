샘플 — 단일 그리드 (오프셋)

연습용 화면입니다. 실제 업무 자료가 아니라 샘플 주문을 다룹니다. 이 시스템의 화면이 어떻게 동작하는지 여기서 마음껏 눌러 보십시오.

메뉴 위치 샘플 › 단일 그리드 (오프셋)

1. 먼저 알아 둘 것

  • 여기 있는 자료는 전부 연습용입니다. 고치거나 지워도 실제 업무에 아무 영향이 없습니다.
  • 이 화면은 이 시스템에서 쓰는 거의 모든 입력 방식을 한자리에 모아 놓았습니다. 다른 화면에서 처음 보는 칸이 나오면 여기서 같은 것을 찾아 연습할 수 있습니다.
  • 컬럼이 서른 개입니다. 실제 업무 화면이 이렇게 많지는 않습니다 — 여기서는 보여 주는 것이 목적입니다.
  • 이 메뉴 묶음은 시스템을 실제로 쓸 때 지워집니다.

2. 찾기

조회조건에 값을 넣고 [조회].

조건이 열두 개이고 입력 방식이 저마다 다릅니다.

조건어떻게 넣나
주문번호글자를 넣습니다 — 일부만 넣어도 찾습니다
고객돋보기를 눌러 창에서 고릅니다. 고르면 아이디와 이름이 함께 채워집니다
주문 상태목록에서 여러 개를 고를 수 있습니다
주문일시작~끝 날짜
납기월월 단위로 고릅니다 (일 단위가 아닙니다)
금액초과 · 미만 을 고를 수 있습니다
태그낱말을 치고 엔터를 누르면 조각이 쌓입니다
소요시간초 단위로 넣습니다
  • 조건 이름 왼쪽의 작은 목록에서 비교 방법(같음 · 포함 · 시작 등)을 바꿀 수 있습니다.
  • 목록 아래에 전체 건수와 페이지 번호가 있습니다.

3. 하기

3-1. 등록·수정·삭제

[행 추가] → 값을 채우고 → [저장]. 고치는 것도 지우는 것도 같은 방식입니다.

칸이 잠겨 있으면 이유가 둘 중 하나입니다.

왜어떻게
잠금이 걸려 있다운영자가 잠근 것입니다 — 상태와 무관하게 닫힙니다
주문 상태가 진행됐다접수 → 확정 → 출고 → 완료로 갈수록 고칠 수 있는 칸이 줄어듭니다
  • 새로 추가한 줄은 언제나 열립니다 — 아직 상태가 없기 때문입니다.
  • 품목이 딸린 주문을 지우려 하면 저장할 때 거부되고 이유를 알려 줍니다.

3-2. 화면 위쪽의 버튼들 — 네 가지가 다릅니다

버튼자리무엇을 하나
표시 범위왼쪽전체 와 내 것 을 바꿉니다. 조회조건이 아니라 보기 방식입니다
확정오른쪽고른 줄을 확정합니다 — 누르면 바로 끝납니다
일괄 재계산오른쪽조회된 전체를 다시 계산합니다 — 창이 열려 값을 묻고, 진행률이 나옵니다
확정과 일괄 재계산이 다르게 동작하는 것을 눈여겨보십시오. 둘 다 실행 이지만 앞은 즉시 끝나고 뒤는 오래 걸려 진행률을 보여 줍니다. 다른 화면에서도 같은 두 가지를 만나게 됩니다.

3-3. 오래 걸리는 작업의 진행률

[일괄 재계산] 을 누르면 순서가 이렇습니다.

  1. 값을 묻는 창이 뜹니다 — 어떤 기준으로 계산할지 고릅니다.
  2. 확인하면 진행률 창이 열립니다.
  3. 끝나면 결과가 나옵니다.

창을 닫아도 작업은 계속됩니다.

3-4. 특별한 칸들 연습하기

칸어떻게
긴 글칸을 두 번 눌러 펼쳐서 씁니다
읽기 전용 긴 글두 번 눌러 읽기만 합니다
태그낱말을 치고 엔터. 창에서 고를 수도 있습니다
고객돋보기 → 창에서 고르면 두 칸이 함께 채워집니다
숨은 칸그리드 설정([⚙])에서 켭니다. 거기에도 없는 칸이 있는데 화면이 판단에만 쓰는 값입니다

3-5. 엑셀로 받기

[⤓] — 현재 페이지와 전체 중에서 고릅니다. 지금 보이는 컬럼만 나갑니다.

6. 자주 묻는 것

  • 여기서 고친 게 실제 업무에 영향이 있나요 — 없습니다. 연습용 자료입니다.
  • 왜 컬럼이 이렇게 많나요 — 이 시스템이 쓰는 입력 방식을 전부 보여 주기 위해서입니다. 실제 업무 화면은 훨씬 적습니다.
  • 다른 화면에서 본 칸을 연습하고 싶습니다 — 대부분 여기 있습니다. 없으면 다른 샘플 화면을 보십시오.
  • 이 메뉴가 없어졌습니다 — 실제 운영을 시작하면서 샘플을 걷어낸 것입니다. 정상입니다.
