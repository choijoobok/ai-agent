# 샘플 — 단일 그리드 (오프셋)

> **연습용 화면입니다.** 실제 업무 자료가 아니라 **샘플 주문**을 다룹니다. 이 시스템의 화면이 어떻게 동작하는지 **여기서 마음껏 눌러 보십시오.**

**메뉴 위치** 샘플 › 단일 그리드 (오프셋)

[샘플 주문 화면 — 컬럼이 서른 개 모두 보입니다](./mockup.html#main)

---

## 1. 먼저 알아 둘 것

- **여기 있는 자료는 전부 연습용입니다.** 고치거나 지워도 실제 업무에 아무 영향이 없습니다.
- **이 화면은 이 시스템에서 쓰는 거의 모든 입력 방식을 한자리에 모아 놓았습니다.** 다른 화면에서 처음 보는 칸이 나오면 **여기서 같은 것을 찾아 연습**할 수 있습니다.
- **컬럼이 서른 개입니다.** 실제 업무 화면이 이렇게 많지는 않습니다 — 여기서는 **보여 주는 것이 목적**입니다.
- 이 메뉴 묶음은 **시스템을 실제로 쓸 때 지워집니다.**

---

## 2. 찾기

조회조건에 값을 넣고 `[조회]`.

**조건이 열두 개이고 입력 방식이 저마다 다릅니다.**

| 조건 | 어떻게 넣나 |
|---|---|
| 주문번호 | 글자를 넣습니다 — 일부만 넣어도 찾습니다 |
| **고객** | **돋보기를 눌러 창에서 고릅니다.** 고르면 아이디와 이름이 함께 채워집니다 |
| 주문 상태 | 목록에서 **여러 개**를 고를 수 있습니다 |
| 주문일 | 시작~끝 날짜 |
| **납기월** | **월 단위**로 고릅니다 (일 단위가 아닙니다) |
| **금액** | **`초과` · `미만`** 을 고를 수 있습니다 |
| **태그** | 낱말을 치고 엔터를 누르면 조각이 쌓입니다 |
| **소요시간** | **초 단위**로 넣습니다 |

- 조건 이름 왼쪽의 작은 목록에서 **비교 방법**(같음 · 포함 · 시작 등)을 바꿀 수 있습니다.
- 목록 아래에 **전체 건수와 페이지 번호**가 있습니다.

---

## 3. 하기

### 3-1. 등록·수정·삭제

`[행 추가]` → 값을 채우고 → `[저장]`. 고치는 것도 지우는 것도 같은 방식입니다.

**칸이 잠겨 있으면 이유가 둘 중 하나입니다.**

| 왜 | 어떻게 |
|---|---|
| **잠금이 걸려 있다** | 운영자가 잠근 것입니다 — 상태와 무관하게 닫힙니다 |
| **주문 상태가 진행됐다** | 접수 → 확정 → 출고 → 완료로 갈수록 고칠 수 있는 칸이 줄어듭니다 |

- **새로 추가한 줄은 언제나 열립니다** — 아직 상태가 없기 때문입니다.
- 품목이 딸린 주문을 지우려 하면 **저장할 때 거부되고 이유를 알려 줍니다.**

### 3-2. 화면 위쪽의 버튼들 — **네 가지가 다릅니다**

| 버튼 | 자리 | 무엇을 하나 |
|---|---|---|
| **표시 범위** | 왼쪽 | *전체* 와 *내 것* 을 바꿉니다. **조회조건이 아니라 보기 방식**입니다 |
| **확정** | 오른쪽 | **고른 줄**을 확정합니다 — **누르면 바로 끝납니다** |
| **일괄 재계산** | 오른쪽 | **조회된 전체**를 다시 계산합니다 — **창이 열려 값을 묻고, 진행률이 나옵니다** |

> **확정과 일괄 재계산이 다르게 동작하는 것을 눈여겨보십시오.** 둘 다 *실행* 이지만 앞은 **즉시 끝나고** 뒤는 **오래 걸려 진행률을 보여 줍니다.** 다른 화면에서도 같은 두 가지를 만나게 됩니다.

### 3-3. 오래 걸리는 작업의 진행률

`[일괄 재계산]` 을 누르면 순서가 이렇습니다.

1. **값을 묻는 창**이 뜹니다 — 어떤 기준으로 계산할지 고릅니다.
2. 확인하면 **진행률 창**이 열립니다.
3. 끝나면 결과가 나옵니다.

**창을 닫아도 작업은 계속됩니다.**

### 3-4. 특별한 칸들 연습하기

| 칸 | 어떻게 |
|---|---|
| **긴 글** | 칸을 두 번 눌러 **펼쳐서** 씁니다 |
| **읽기 전용 긴 글** | 두 번 눌러 **읽기만** 합니다 |
| **태그** | 낱말을 치고 엔터. 창에서 고를 수도 있습니다 |
| **고객** | 돋보기 → 창에서 고르면 **두 칸이 함께** 채워집니다 |
| **숨은 칸** | 그리드 설정(`[⚙]`)에서 켭니다. **거기에도 없는 칸이 있는데** 화면이 판단에만 쓰는 값입니다 |

### 3-5. 엑셀로 받기

`[⤓]` — 현재 페이지와 전체 중에서 고릅니다. **지금 보이는 컬럼만** 나갑니다.

## 4. 안 될 때

| 이런 일이 생기면 | 이유 | 어떻게 하나 |
|---|---|---|
| 칸이 회색이고 안 고쳐집니다 | **잠겼거나** 주문 상태가 진행됐습니다 | 그리드 설정에서 `상태` 칸을 확인합니다 |
| 지우려는데 저장이 거부됩니다 | **품목이 딸려 있습니다** | 메시지가 이유를 말해 줍니다 |
| `[확정]` 이 눌리지 않습니다 | 줄을 고르지 않았습니다 | 체크박스로 고릅니다 |
| 진행률 창을 닫았습니다 | **작업은 계속됩니다** | 조금 뒤 `[조회]` 로 결과를 확인합니다 |
| 조회가 느립니다 | 조건이 넓습니다 | 기간이나 상태로 좁힙니다 |
| 메뉴가 보이지 않습니다 | 샘플 메뉴 권한이 없거나 **이미 걷어냈습니다** | 관리자에게 확인합니다 |

## 5. 다른 메뉴와의 관계

**먼저 해야 하는 것**

- 없습니다. 연습용 자료가 이미 들어 있습니다.

**여기서 저장하면 바뀌는 곳**

| 어디가 | 어떻게 |
|---|---|
| **다른 샘플 화면들** | **같은 주문 자료**를 봅니다 — 여기서 고치면 거기서도 보입니다 |

**같이 보는 화면**

| 무엇을 연습하려면 | 어디로 |
|---|---|
| 총 건수 없이 넘기는 목록 | **[단일 그리드 (커서)]** |
| 위아래로 나뉜 화면 | **[마스터-디테일 (상하)]** |
| 좌우로 나뉜 화면 | **[마스터-디테일 (좌우)]** |
| 아래에 탭이 있는 화면 | **[마스터-디테일 (복수 탭)]** |
| 엑셀로 한꺼번에 올리기 | **[엑셀 업로드]** |

## 6. 자주 묻는 것

- **여기서 고친 게 실제 업무에 영향이 있나요** — 없습니다. 연습용 자료입니다.
- **왜 컬럼이 이렇게 많나요** — 이 시스템이 쓰는 **입력 방식을 전부 보여 주기 위해서**입니다. 실제 업무 화면은 훨씬 적습니다.
- **다른 화면에서 본 칸을 연습하고 싶습니다** — 대부분 여기 있습니다. 없으면 다른 샘플 화면을 보십시오.
- **이 메뉴가 없어졌습니다** — 실제 운영을 시작하면서 샘플을 걷어낸 것입니다. 정상입니다.
