# 요건 정의서 — 공통 메뉴 진입

## 개요

- **무엇을 하는 화면인가**: 메뉴 이름으로 찾아 바로 열고, 자주 쓰는 메뉴를 즐겨찾기로 둔다. 메뉴 트리에서 현재 셸 탭·셸 새 탭·브라우저 새 탭 또는 창으로 연다.
- **프로세스상 위치**: (선행) `MENU_MGMT` 가 트리를 만들고 권한이 걸러진다 → **이 화면**(사용자가 고른다) → (후행) 선택이 `SYS_USER_MENU_STAT` 에 쌓여 사용 통계가 된다.
- **바꾸면 어디가 흔들리나**: 메뉴 트리의 열기는 사용 통계를 한 곳에 기록한다. 브라우저 열기는 `window.open`이 실제 창 객체를 돌려줄 때만 기록하므로, 팝업 차단은 통계에 섞이지 않는다.

> **이 문서는 `docs/design/60-screen-auth.md` §10 에서 옮겼다**(2026-09-04 · 그 폴더는 폐지됐다).

> **문서 상태: 구현됨** — 셸의 헤더에서 연다.

---

## 0. 메타

| 항목 | 값 |
|---|---|
| 자리 | 헤더 → 모달 |
| 메뉴코드 | **없음** |
| 프론트 폴더 | `sources/frontend/src/layouts/ShellLayout/` — `MenuEntryModal.tsx`와 `ShellSider.tsx`. 검색은 `shared/authz/menuSearch`, 즐겨찾기는 `shared/favorite/` 가 갖는다. **`modules/system/features/menu/` 가 아니다** — 그쪽은 메뉴 트리 관리 화면(`/admin/system/menu`)이다 |
| 화면 유형 | 모달과 좌측 메뉴 트리 — 검색·즐겨찾기는 같은 모달 컴포넌트 |
| 처리 유형 | 조회 + 실행(선택) |
| 액션 권한 | **해당 없음** |

---

## 1. 화면 구성

- **검색 결과가 1건이면 바로 열고, 2건 이상이면 모달**을 띄운다.
- 즐겨찾기 목록은 **개수 상한이 없다** — 모달 목록이 스크롤될 뿐이다.

---

## 2. 조회조건

메뉴 이름 한 칸. **매칭은 번역된 메뉴명 포함 여부이며 클라이언트가 거른다** — 트리가 이미 내려와 있으므로 서버에 묻지 않는다.

---

## 3. 조회 — 테이블과 범위

### 3-1. 사용 테이블 · 결합

| 테이블 | 읽기 | 쓰기 |
|---|---|---|
| (메뉴 트리) | 셸이 이미 받아 둔 것 | — |
| `SYS_USER_FAVORITE` | 즐겨찾기 | 추가 · 삭제 |
| `SYS_USER_MENU_STAT` | — | 선택 기록 |

### 3-2. 고정 조건

**트리는 유효 권한으로 이미 걸러져 온다** — 이 화면이 권한을 다시 묻지 않는다.

---

## 4. 컬럼

메뉴명 · 경로(조상). 즐겨찾기는 별 표시.

---

## 5. 버튼 · 액션

| 조작 | API |
|---|---|
| 메뉴 선택 | `POST /api/common/system/menu/saveSelect { menuCd }` |
| 즐겨찾기 추가·삭제 | `/api/common/system/favorite/**` |

**선택 통계는 메뉴를 여는 행동에만 붙는다** — 탭바 이동·화면 안 버튼은 메뉴 선택이 아니다.

---

## 6. 규칙 — 저장 · 실행

### 6-1. 실제 메뉴 열기만 월별 사용 횟수에 넣는다

- 좌측 메뉴 트리에서 현재 셸 탭 또는 셸 새 탭으로 열면 한 번 기록한다.
- 좌측 메뉴 트리에서 브라우저 새 탭 또는 창으로 열고 `window.open`이 성공하면 한 번 기록한다. 탭과 창의 형태는 브라우저 설정이 정한다.
- 탭바에서 기존 탭으로 이동하거나 화면 안에서 버튼을 누르는 행동은 기록하지 않는다.
- 팝업 차단 등으로 브라우저 창이 열리지 않으면 기록하지 않는다.

### 6-2. 영향 테이블

`SYS_USER_MENU_STAT` 한 행. 즐겨찾기를 고치면 `SYS_USER_FAVORITE`.

---

## 7. API

`/api/common/system/**`. **인가 시드의 입력이 아니다.**

---

## 8. 시드 · 데이터 전제

메뉴 이름이 `menu.{MENU_CD}` 메시지 키로 있어야 검색이 걸린다 — 번역된 이름으로 찾기 때문이다.

---

## 9. 테스트 케이스

> **요건이 지켜졌는지 묻는 표다.** 위의 절들이 *무엇을* 정했다면 여기는 *그것이 지켜졌는가* 다.
> **되면 안 되는 것**을 함께 담는다 — 그것이 빠지면 케이스가 그림 검사로 줄어든다.
>
> **목업(`mockup.html`)은 이 표와 위의 절들로부터 생성되는 파생물이다** — 케이스를 목업에서
> 고치지 않는다. 고칠 곳은 여기고, 고친 뒤 `/mockup` 이 목업을 다시 만든다.

### 검색

| # | 조작 · 상황 | 기대 |
|---|---|---|
| `MM-01` | 결과가 **1건** | **모달을 띄우지 않고 바로 연다** |
| `MM-02` | 결과가 **0건** | **빈 상태**(UX-11) |
| `MM-03` | 결과가 **2건 이상** | 이 모달 |
| `MM-04` | 폴더명(예: *기준정보*)을 친다 | **그 폴더 하위 전체가 걸리지 않는다** — 매칭은 **메뉴명만** 본다 **(되면 안 되는 것)** |
| `MM-05` | `사 용 자` · `USER` 로 친다 | **공백 제거 + 소문자화** 후 **포함** 판정 |
| `MM-06` | `ㅅㅇㅈ` 로 친다 | **걸리지 않는다** — 초성 검색은 없다 |
| `MM-07` | 같은 검색어를 두 번 친다 | **결과 순서가 같다** — "일치 위치 우선" 을 쓰지 않는다 |
| `MM-08` | 검색 중 네트워크 확인 | **서버 왕복이 없다** — 프론트가 이미 권한 메뉴 트리를 갖는다 |
| `MM-09` | 구조 노드가 검색어에 맞는 경우 | **결과에 없다** — `MENU_URL` 이 없어 열 수 없다 **(되면 안 되는 것)** |

### 즐겨찾기

| # | 조작 · 상황 | 기대 |
|---|---|---|
| `MM-10` | 행 우측 화살표 vs 키보드 위아래 | **다른 것**이다 — 순서 변경 vs 항목 이동. 키보드 순서 변경은 `Alt`+위아래 |
| `MM-11` | 즐겨찾기를 많이 추가 | **상한이 없다** — 모달 크기를 조절할 수 있다 |
| `MM-12` | 순서를 연달아 바꾼다 | **저장 버튼이 없고** 디바운스 후 **마지막 상태만** 보낸다 |
| `MM-13` | 즐겨찾기에 있는 메뉴의 **권한을 잃는다** | **행은 남고 표시만 멈춘다.** 권한이 돌아오면 다시 나타난다 |

### 세 탭 공통

| # | 조작 · 상황 | 기대 |
|---|---|---|
| `MM-14` | 세 목록(검색 · 즐겨찾기 · 자주 쓰는) 각각 | **같은 권한 게이트**를 지난다 — 권한 없는 메뉴가 새지 않는다 |
| `MM-15` | 자주 쓰는 메뉴 집계 | **월 버킷 · 이번 달 포함 3개월**. 메뉴 트리의 현재 셸 탭·셸 새 탭·성공한 브라우저 새 탭/창 열기만 센다. 기존 탭 이동·화면 버튼·팝업 차단은 세지 않는다 |
| `MM-16` | 브라우저 새 탭 또는 창 열기 | `window.open`이 창 객체를 돌려줄 때만 `menuCd` 하나를 통계 API에 보낸다 **(되면 안 되는 것: 차단된 팝업을 사용으로 기록)** |
| `MM-17` | 구조 노드 | **어느 탭에도 나타나지 않는다** **(되면 안 되는 것)** |
| `MM-18` | 같은 메뉴를 두 탭에서 동시에 즐겨찾기에 넣는다 | 둘 다 성공으로 끝나고 즐겨찾기 행은 하나다 |
