# 비밀번호 강제 변경

초기화되었거나 사용 기간이 만료된 비밀번호를 바꾼 뒤 업무 화면으로 이동합니다.

**진입 위치** 로그인 후 비밀번호 변경이 필요할 때 자동으로 열립니다.

## 1. 먼저 알아 둘 것

현재 비밀번호를 준비합니다. 변경을 마치기 전에는 다른 업무 화면으로 이동할 수 없습니다.

[비밀번호 변경 화면](./mockup.html#main)

## 2. 비밀번호 바꾸기

1. **현재 비밀번호**를 입력합니다.
2. **새 비밀번호**를 입력하며 아래에 표시된 규칙을 확인합니다.
3. **새 비밀번호 확인**에 같은 값을 다시 입력합니다.
4. 입력칸 아래 오른쪽 끝의 **[비밀번호 변경]**을 누릅니다. 성공하면 업무 화면으로 이동합니다.

지금 변경하지 않으려면 왼쪽 끝의 **[로그아웃]**을 누릅니다.

## 3. 안 될 때

- 변경 버튼이 비활성화되어 있으면 새 비밀번호의 규칙 충족 여부를 확인합니다.
- 현재 비밀번호가 틀리거나 이전 비밀번호를 재사용하면 화면의 오류 안내에 따라 다시 입력합니다.
- 규칙을 불러오지 못하면 **[다시 시도해 주세요.]**를 누릅니다. 이때도 로그아웃할 수 있습니다.

## 4. 다른 화면과의 관계

변경 성공 후에는 메인 화면을 사용할 수 있습니다. 이후 자발적인 비밀번호 변경은 **내 프로필**에서 합니다.
