# 요건 정의서 — 설정 모달

> **CR-028 목표 경계(2026-10-29):** 이 문서의 기존 소스 역작성은 현재 구현 근거다. system 계정·인증·세션·SYS_USER 참조는 관리자 영역에 한정한다. Portal 계정/인증은 ARCH-050의 별도 계약과 SCR-113~115를 사용하며 같은 문자열 ID로 관리자 이름·이력·개인 설정을 연결하지 않는다. 통합 감사의 영역 구분·이행 및 상세 화면 변경은 소유 P3 후속이고 현재 소스에서 구현됐다는 뜻이 아니다.


## 개요

- **무엇을 하는 화면인가**: 언어 · 테마 · 글꼴 · 그리드 표시를 사용자가 고른다. 그룹 넷.
- **프로세스상 위치**: 선행이 없다. 셸 사용 중 언제든 열고, **저장 버튼 없이 즉시 반영**된다.
- **바꾸면 어디가 흔들리나**: **언어만 서버에 남고**(`SYS_USER.LOCALE_CD`) 나머지는 `localStorage` 다 — 기기를 바꾸면 언어만 따라오고 나머지는 초기값이다.

> **이 문서는 `docs/design/60-screen-auth.md` §7 에서 옮겼다**(2026-09-04 · 그 폴더는 폐지됐다).

> **문서 상태: 구현됨** — `modules/system/public/settings/SettingsModal.tsx`.

| 항목 | 어디 | 왜 |

## 6. 규칙 — 저장 · 실행

### 6-1. 영향 테이블

언어를 바꾸면 `SYS_USER.LOCALE_CD` 한 컬럼. 나머지는 DB 를 건드리지 않는다.

## 7. API

언어 저장만 `/api/common/**`. **인가 시드의 입력이 아니다.**

## 8. 시드 · 데이터 전제

지원 언어는 `LANG_CD` 공통코드가 정한다 — 이 화면이 후보를 만들지 않는다.

## 9. 테스트 케이스

> **요건이 지켜졌는지 묻는 표다.** 위의 절들이 *무엇을* 정했다면 여기는 *그것이 지켜졌는가* 다.
> **되면 안 되는 것**을 함께 담는다 — 그것이 빠지면 케이스가 그림 검사로 줄어든다.
>
> **목업(`mockup.html`)은 이 표와 위의 절들로부터 생성되는 파생물이다** — 케이스를 목업에서
> 고치지 않는다. 고칠 곳은 여기고, 고친 뒤 `/mockup` 이 목업을 다시 만든다.

### 케이스

| # | 조작 · 상황 | 기대 |
|---|---|---|
| `ST-01` | 저장 버튼 찾기 | **없다** — 즉시 반영이다 |
| `ST-02` | 테마·글꼴을 바꾼다 | **서버 왕복 없이** 즉시 바뀐다 — `localStorage` |
| `ST-03` | 다른 PC 에서 로그인 | **UI 설정이 따라오지 않는다** — 기기의 속성이다 |
| `ST-04` | **언어**를 바꾼다 | **①미저장 확인 → ②서버 저장 → ③`localStorage` → ④재로드** 순서로 돈다 |
| `ST-05` | 언어 저장이 **서버에서 실패** | **`localStorage` 를 갱신하지 않는다** — 서버가 먼저인 이유 **(되면 안 되는 것)** |
| `ST-06` | 언어를 바꾼 뒤 로그아웃 → 로그인 화면 | **바꾼 언어로 그려진다** — `localStorage` 가 1순위 |
| `ST-07` | 언어를 바꾸고 **재로드하지 않는다면** | 이미 떠 있는 **서버 발 에러 메시지**가 이전 언어로 남는다 — 그래서 재로드한다 |
| `ST-08` | 그리드 글꼴 크기를 바꾼다 | **본문 크기는 그대로**다 — 둘은 별개 설정 |
| `ST-09` | 저장 위치를 표로 대조 | **언어만 서버**(`SYS_USER.LOCALE_CD`), 나머지 전부 `localStorage` |
