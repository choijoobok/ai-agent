# 요건 정의서 — 세션 만료 예고 · 재인증 모달

## 개요

- **무엇을 하는 화면인가**: 세션이 끝나기 **전**에 알리고 연장할 기회를 준다. 그래도 만료되면 **로그아웃하지 않고 재인증 모달로 바뀌어 탭과 입력값을 지킨다.**
- **프로세스상 위치**: 셸 사용 중 → 만료 임박 → **예고 모달** → (미응답) → **재인증 모달** → 재인증하면 하던 일로 복귀.
- **바꾸면 어디가 흔들리나**: *지금 로그아웃* 은 **명시적 로그아웃**이라 탭을 비운다. 재인증은 비우지 않는다 — 둘을 섞으면 **작업 중이던 탭이 사라진다.**

> **이 문서는 `docs/design/60-screen-auth.md` §5 에서 옮겼다**(2026-09-04 · 그 폴더는 폐지됐다).

> **문서 상태: 구현됨** — `features/auth/components/ExpiryWarningModal.tsx` · `ReauthModal.tsx`.

## 1. 화면 구성

### 1-1. 모달 둘은 시점이 다르다

| | 예고 모달 | 재인증 모달 |
|---|---|---|
| 시점 | 만료 **전** | 만료 **후** |
| 입력 | 없다 | **비밀번호만**(ID 는 읽기 전용) |
| 출구 | 연장 · 지금 로그아웃 | 재인증 · 다른 계정으로 · (불가 시) 로그아웃 |
| 배경 | 그대로 | **블러** |

**표시 항목**(예고) — 남은 시간 카운트다운 · *연장* · *지금 로그아웃*.

## 4. 컬럼

재인증 모달의 입력은 **비밀번호 하나**다. 로그인 ID 는 읽기 전용으로 보인다.

---

## 5. 버튼 · 액션

| 버튼 | API | 비고 |
|---|---|---|
| 연장 | `POST /api/common/auth/heartbeat` | **자동 연장은 두지 않는다** |
| 지금 로그아웃 | 로그아웃 | **명시적 로그아웃 — 탭을 비운다** |
| 재인증 | 재인증 | 성공하면 **탭과 입력값이 그대로 남는다** |
| 다른 계정으로 | 로그아웃 후 로그인 | 탭을 비운다 |

> **자동 연장을 두지 않는 이유** — 자리를 비운 화면이 스스로 세션을 이어 가면 **만료가 있는 것과 없는 것이 같아진다.**

---

## 6. 규칙 — 저장 · 실행

### 6-1. 상태 전이

```
사용 중 ──(만료 임박)──→ 예고 모달 ──(연장)──→ 사용 중
                            │
                            ├──(지금 로그아웃)──→ 로그인 화면 · 탭 비움
                            │
                            └──(미응답 · 만료)──→ 재인증 모달 ──(재인증)──→ 사용 중
                                                        └──(로그아웃)──→ 로그인 화면 · 탭 비움
```

**미응답으로 만료되면 로그아웃하지 않는다.** 이것이 이 화면의 핵심이다 — 만료를 로그아웃으로 처리하면 **작성 중이던 입력이 통째로 사라진다.**

### 6-2. 영향 테이블

없다. 세션만 바뀐다.

## 9. 테스트 케이스

> **요건이 지켜졌는지 묻는 표다.** 위의 절들이 *무엇을* 정했다면 여기는 *그것이 지켜졌는가* 다.
> **되면 안 되는 것**을 함께 담는다 — 그것이 빠지면 케이스가 그림 검사로 줄어든다.
>
> **목업(`mockup.html`)은 이 표와 위의 절들로부터 생성되는 파생물이다** — 케이스를 목업에서
> 고치지 않는다. 고칠 곳은 여기고, 고친 뒤 `/mockup` 이 목업을 다시 만든다.

### 예고 상태

| # | 조작 · 상황 | 기대 |
|---|---|---|
| `SE-01` | 예고 모달의 닫기(`✕`) 찾기 | **없다** — 닫으면 연장했다고 착각하고 작업을 잃는다 |
| `SE-02` | 남은 시간 표시 중 네트워크 확인 | **서버에 매초 묻지 않는다** — 클라이언트 카운트다운. 물으면 **그 요청이 세션을 연장**한다 |
| `SE-03` | "계속 사용" 을 누른다 | `POST /api/common/auth/heartbeat` |
| `SE-04` | 아무것도 하지 않고 둔다 | **자동 연장되지 않는다** — 유휴 타임아웃의 목적이다 **(되면 안 되는 것)** |
| `SE-05` | 미응답으로 만료 | **로그아웃 네 경로 중 *만료*** 로 수렴한다 — 같은 함수 |

### 재인증 모달

| # | 조작 · 상황 | 기대 |
|---|---|---|
| `SE-06` | 재인증 모달의 닫기 찾기 | **없다** — 출구는 재인증 · 다른 계정 · (불가 시) 로그아웃 셋 |
| `SE-07` | 로그인 ID 를 고치려 한다 | **불가 — 고정**이다. ID 가 다르면 **이전 사용자의 권한으로 열린 탭**을 유지할 수 없다 **(되면 안 되는 것)** |
| `SE-08` | 재인증 성공 | **모달만 닫힌다.** 새 `menus·permissions` 로 **탭 정리를 한 번** 돈다 |
| `SE-09` | "다른 계정으로" 를 누른다 | **정식 로그아웃** — 탭·캐시를 정리하고 로그인 화면으로 |
| `SE-10` | 401 을 받은 요청 | **자동 재시도하지 않는다** — 저장이었으면 중복 실행이 된다 **(되면 안 되는 것)** |
| `SE-11` | 잠김·비활성·기간 만료·권한 공집합으로 재인증 | **모달에서 사유를 보이고 정식 로그아웃으로 전환**한다 |
| `SE-12` | **F5** 후 401 을 받는다 | **이 모달이 뜨지 않는다 — 로그인 화면**이다. `authStore` 가 메모리라 ID 를 잃고, 그때는 **유지할 탭도 없다** |
| `SE-13` | `localStorage` 에서 로그인 ID 찾기 | **없다** — 로그아웃 뒤에도 남는 이전 사용자 정보가 된다 **(되면 안 되는 것)** |
