# 요건 정의서 — 설정 모달

## 개요

- **무엇을 하는 화면인가**: 언어 · 테마 · 글꼴 · 그리드 표시를 사용자가 고른다. 그룹 넷.
- **프로세스상 위치**: 선행이 없다. 셸 사용 중 언제든 열고, **저장 버튼 없이 즉시 반영**된다.
- **바꾸면 어디가 흔들리나**: **언어만 서버에 남고**(`SYS_USER.LOCALE_CD`) 나머지는 `localStorage` 다 — 기기를 바꾸면 언어만 따라오고 나머지는 초기값이다.

> **이 문서는 `docs/design/60-screen-auth.md` §7 에서 옮겼다**(2026-09-04 · 그 폴더는 폐지됐다).

> **문서 상태: 구현됨** — `features/settings/SettingsModal.tsx`.

## 1. 화면 구성

그룹 넷. **저장 버튼을 두지 않고 고르는 즉시 반영**한다 — 미리보기와 결과가 같아야 고를 수 있다.

## 3. 조회 — 테이블과 범위

### 3-1. 저장 위치가 항목마다 다르다

| 항목 | 어디 | 왜 |
|---|---|---|
| **언어** | **서버** — `SYS_USER.LOCALE_CD` | 서버가 문구를 완성해 내려주므로 서버가 알아야 한다 |
| 테마 · 글꼴 · 그리드 | **`localStorage`** | **UI 설정은 기기의 속성**이다 — 사무실 모니터와 노트북에서 같아야 할 이유가 없다 |

### 4-1. 그룹 넷

일반(언어) · 테마 · 글꼴(크기) · 그리드(행 높이 등). 기본값은 미결(§9).

## 5. 버튼 · 액션

## 6. 규칙 — 저장 · 실행

### 6-1. 영향 테이블

언어를 바꾸면 `SYS_USER.LOCALE_CD` 한 컬럼. 나머지는 DB 를 건드리지 않는다.

## 7. API

언어 저장만 `/api/common/**`. **인가 시드의 입력이 아니다.**

## 8. 시드 · 데이터 전제

지원 언어는 `LANG_CD` 공통코드가 정한다 — 이 화면이 후보를 만들지 않는다.
