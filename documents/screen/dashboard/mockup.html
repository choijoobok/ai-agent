1. 기본 상태 — 위젯 슬롯만 있다

서버를 부르지 않는다. 인사말과 숫자 둘은 전부 로그인할 때 이미 받은 값에서 나온다 — 로그인 응답이 메뉴 목록과 권한 목록을 함께 주므로 세어 보기만 하면 된다. 고정 탭이라 항상 살아 있고, 그래서 여기에 폴링이나 무거운 그리드를 두면 그 비용을 모든 사용자가 로그인 내내 낸다.

여기가 위젯이 들어올 자리다. 무엇을 놓을지는 아직 정해지지 않았고, 업무 데이터 위젯을 두면 위젯 단위 권한이 따라온다 — 그것은 위젯을 정할 때 함께 정한다. 차트 라이브러리도 아직 없다.

2. 왜 이 화면에 아무것도 없나 — 넷이 걸려 있다

  • 위젯 단위 권한이 없다 — 인가의 단위는 (메뉴, 액션) 이고 위젯은 그 단위가 아니다. 업무 데이터를 얹는 순간 이 카드를 누가 보는가 가 새 질문이 된다
  • 차트 라이브러리가 없다 — 들이는 결정을 아직 하지 않았다
  • 고정 탭이라 항상 살아 있다 — 폴링을 두면 그 비용을 모든 사용자가 로그인 내내 낸다
  • 그래서 지금은 슬롯이다 — 로그인 응답에 이미 있는 값 둘만 센다. 서버 호출이 없으므로 이 화면의 API 는 0개이며, 그것이 SYS_MENU_API 에 DASHBOARD 행이 없는 이유다
비어 있는 것이 결함이 아니다 — 이 템플릿은 업무 화면 이 아니라 업무 화면을 만드는 바탕 이고, 대시보드의 내용은 고객사가 정한다
