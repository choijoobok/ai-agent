# 스케줄 관리

> **정기적으로 도는 작업(배치)을 등록하고 주기를 정합니다.** 켜고 끄고, 필요하면 **지금 당장 한 번** 돌립니다.

**메뉴 위치** 시스템 › 배치 › 스케줄 관리

[스케줄 관리 화면 — 위는 등록, 아래는 그 배치의 최근 실행 이력](./mockup.html#main)

---

## 1. 먼저 알아 둘 것

- **잘못 등록하면 오류 없이 조용히 안 돕니다.** 크론을 틀리면 아무 말 없이 그냥 안 돌고, 쿨다운을 잘못 넣으면 매번 건너뜁니다 — 그래서 **저장할 때 여러 가지를 확인합니다.**
- **[실행 이력]과 짝입니다.** 여기가 *왜 이렇게 도나* 이고 거기가 *어떻게 돌았나* 입니다. **두 화면을 오가는 것이 보통의 작업**입니다.
- **`배치 구현` 목록이 비어 있으면 정상일 수 있습니다** — 아직 만들어진 작업이 없다는 뜻입니다. 목록은 **배포에 담겨 옵니다.**
- **끄기 전에 `설명` 을 반드시 읽으십시오.** 저장할 때 그 글이 그대로 나옵니다 — **거기 적은 사람이 무엇이 멈추는지 알려 주려고 쓴 것**입니다.

---

## 2. 찾기

**대개 그냥 `[조회]` 를 누릅니다.** 등록이 많지 않아 한 화면에 다 들어옵니다.

| 이렇게 찾고 싶다 | 이렇게 넣습니다 |
|---|---|
| 이름을 알 때 | `배치명`에 조각을 넣습니다 |
| 같은 작업을 쓰는 등록 전부 | `배치 구현`에 넣습니다 — **같은 작업을 여러 번 등록할 수 있습니다** |
| 꺼 둔 것만 | `사용 여부`를 *미사용* 으로 |

- **처음부터 꺼진 것도 함께 나옵니다.** 감춰 두면 **같은 배치를 또 만들게 되고**, 그때는 저장이 실패합니다.
- 위에서 **한 줄을 고르면** 아래에 그 배치의 **최근 10건**이 나옵니다. 전체는 [실행 이력]에서 봅니다.

---

## 3. 하기

### 3-1. 배치 등록하기

1. `[행 추가]`.
2. 채워야 할 것이 **다섯**입니다.

| 칸 | 무엇을 넣나 |
|---|---|
| **배치 ID** | 이 등록의 이름. **나중에 바꿀 수 없습니다** |
| **배치명** | 사람이 읽을 이름 |
| **설명** | **끄면 무슨 일이 생기는지**를 씁니다 — 나중에 이 글이 확인 창에 그대로 나옵니다 |
| **배치 구현** | 목록에서 고릅니다. 직접 칠 수 없습니다 |
| **크론** | 언제 돌지 — `0 0 9 * * MON-FRI` 처럼 |

3. `[저장]`.
4. **`다음 실행` 칸을 확인합니다** — 크론을 제대로 썼는지 여기서 눈으로 확인됩니다. 평일 9시로 썼는데 여기가 월요일 9시면 맞게 쓴 것입니다.

- **`사용` 은 켜진 채로 만들어집니다.** 만들자마자 꺼져 있으면 왜 안 도는지 찾게 되기 때문입니다.
- **저장하기 전에는 아래가 잠깁니다** — 아직 실행된 적이 없으니 볼 것이 없습니다.

### 3-2. 파라미터 넣기

`파라미터` 칸은 **JSON 형식**입니다. 칸을 두 번 눌러 펼쳐 씁니다.

```
{"days": 90, "chunkSize": 1000}
```

- **형식이 틀리면 저장이 거부됩니다.**
- 무엇을 넣어야 하는지는 그 작업을 만든 개발 담당자가 압니다.
- **파라미터로는 검색할 수 없습니다.**

### 3-3. 쿨다운과 락 만료

| 칸 | 무엇인가 | 조심할 점 |
|---|---|---|
| **쿨다운(초)** | 마지막 실행 뒤 **이만큼 지나야 다시 돈다** | **크론 주기보다 길면 저장이 거부됩니다** — 그러면 매번 건너뛰기 때문입니다 |
| **락 만료(초)** | 이 시간이 지나도 안 끝나면 **다른 노드가 이어받을 수 있게** 잠금을 푼다 | 실제 걸리는 시간보다 넉넉히 |

- **새로 만들면 쿨다운이 `0`(끔)입니다.** 크론과의 관계를 모른 채 값을 넣으면 저장이 막히기 때문입니다.

### 3-4. 지금 한 번 돌리기

1. 줄을 고르고 `[즉시 실행]`.
2. 결과 창이 **건별로** 알려 줍니다.

| 결과 | 무슨 뜻인가 |
|---|---|
| *시작했습니다* | 돌기 시작했습니다 |
| ***다른 노드에서 실행 중*** | **어느 노드에서 몇 시에 시작했는지** 함께 알려 줍니다 |
| *거부됨* | 그 밖의 이유로 시작하지 못했습니다 |

- **저장하지 않은 변경이 있으면 실행되지 않습니다.** 고친 크론이 반영되지 않은 채 도는 것을 막기 위해서입니다 — **저장하고 나서 실행하십시오.**
- 실행하면 **아래 목록이 다시 읽혀** *실행 중* 줄이 바로 보입니다.
- **진행률 창은 없습니다.** 진행은 아래 목록의 그 줄로 봅니다.

### 3-5. 배치 끄기

`사용` 을 끄고 `[저장]`. 저장 전에 **그 배치의 `설명` 이 그대로 나옵니다.**

[끄기 전에 설명을 그대로 읽어 줍니다](./mockup.html#disable)

> **반드시 읽으십시오.** *"껐다 켜면 저절로 따라잡는다"* 인 배치와 *"건너뛴 구간은 영영 빈다"* 인 배치는 **끄는 결정의 무게가 다릅니다.**

- **켤 때는 확인하지 않습니다.** 켜는 것은 되돌릴 수 있고 끄는 것은 시간이 가기 때문입니다.

### 3-6. 배치 지우기

**꺼져 있고 실행 중이 아니어야** 지울 수 있습니다.

- 체크박스에 마우스를 올리면 **무엇이 막고 있는지** 알려 줍니다.
- **실행 이력은 막지 않습니다** — 등록을 지워도 이력은 남습니다(그 화면에 *(삭제된 배치)* 로 보입니다).
- **대개는 지우지 말고 끄는 것이 맞습니다.**

### 3-7. 아래쪽 — 최근 실행 이력

**최근 10건**입니다. 보기만 합니다.

- **줄을 두 번 누르면** [실행 이력]이 그 배치로 열립니다.
- **아무 줄도 없으면** *아직 실행된 적이 없습니다* 라고 뜹니다 — **그 자체가 신호**입니다(꺼져 있었거나 크론이 안 맞았다는 뜻).

### 3-8. 엑셀

이 화면에는 **엑셀이 없습니다.** 등록은 여기서 고쳐야 하고, 파라미터의 중괄호가 든 파일은 읽기도 어렵기 때문입니다.

## 4. 안 될 때

| 이런 일이 생기면 | 이유 | 어떻게 하나 |
|---|---|---|
| *이미 있는 배치 ID 입니다.* | 같은 ID 가 있습니다. **꺼 둔 것도 남아 있습니다** | `사용 여부`를 비우고 조회해 확인합니다 |
| *배치명은 필수입니다.* / *설명은 필수입니다.* | 비었습니다 | 채웁니다. **설명은 나중에 꼭 필요합니다** |
| *등록된 배치 구현이 아닙니다.* | 목록에 없는 값입니다 | 목록에서 고릅니다 |
| *크론 표현식이 올바르지 않습니다.* | 형식이 틀렸습니다 | 바로잡고, 저장 뒤 **`다음 실행`** 을 확인합니다 |
| *파라미터가 올바른 JSON 이 아닙니다.* | 중괄호·따옴표·쉼표가 틀렸습니다 | 형식을 바로잡습니다 |
| ***쿨다운이 크론 주기보다 깁니다.*** | 그대로 두면 **매번 건너뜁니다** | 쿨다운을 줄이거나 크론을 늘립니다 |
| *켜져 있거나 실행 중이어서 삭제할 수 없습니다.* | 게이트에 걸렸습니다 | 먼저 끄고 실행이 끝나기를 기다립니다 |
| *이미 실행 중입니다.* | 그 배치가 지금 돌고 있습니다 | 끝나기를 기다립니다 |
| *없는 배치입니다.* | 다른 사람이 먼저 지웠습니다 | 다시 조회합니다 |
| **`[즉시 실행]` 을 눌렀는데 저장하라고 합니다** | 저장하지 않은 변경이 있습니다 | 먼저 `[저장]` |
| **`배치 구현` 목록이 비어 있습니다** | 배포에 배치가 하나도 없습니다 | 개발 담당자에게 확인합니다 |
| **등록했는데 안 돕니다** | ① `사용`이 꺼져 있거나 ② 크론이 다르거나 ③ 쿨다운에 걸렸습니다 | **`다음 실행`** 을 보고, [실행 이력]에서 *건너뜀* 줄이 있는지 봅니다 |
| 아래 목록이 잠겨 있습니다 | 저장하지 않은 새 줄입니다 | 먼저 저장하고 다시 고릅니다 |
| `배치 ID` 칸이 안 고쳐집니다 | 저장된 줄의 ID 는 바꿀 수 없습니다 | 새로 만들고 옛것을 끕니다 |

## 5. 다른 메뉴와의 관계

**먼저 해야 하는 것**

| 무엇을 | 어디서 | 왜 |
|---|---|---|
| **배치 만들기** | **개발(배포)** | `배치 구현` 목록에 없으면 등록할 수 없습니다 |

**여기서 저장하면 바뀌는 곳**

| 어디가 | 어떻게 |
|---|---|
| **정해진 시각의 자동 실행** | 크론대로 돕니다 |
| **[실행 이력]** | 돌 때마다 줄이 하나 생깁니다 |
| 기록 자동 정리 | **파기 배치가 여기 등록되어 있고 기본이 꺼져 있습니다** — 켜야 오래된 기록이 지워집니다 |

**같이 보는 화면**

| 무엇이 궁금한가 | 어디로 |
|---|---|
| 어떻게 돌았나 · 왜 실패했나 | **[실행 이력]** — 아래 목록을 두 번 눌러 바로 갑니다 |
| 기록을 며칠 보관할지 | **[시스템 환경설정]** — 기간만 바꿔도 **여기 파기 배치가 꺼져 있으면 아무것도 안 지워집니다** |

---

## 6. 자주 묻는 것

- **크론을 어떻게 쓰나요** — `초 분 시 일 월 요일` 순서입니다. 저장 뒤 **`다음 실행`** 이 맞는지 확인하는 것이 가장 확실합니다.
- **같은 작업을 여러 번 등록해도 되나요** — 됩니다. 파라미터만 바꿔 여러 개 등록하는 것이 정상적인 사용입니다.
- **끄면 그동안 못 돈 것은 어떻게 되나요** — **배치마다 다릅니다.** `설명` 칸에 적혀 있어야 하고, 끄기 전 확인 창이 그것을 읽어 줍니다.
- **즉시 실행이 자꾸 거부됩니다** — 다른 노드에서 돌고 있는 것입니다. 결과 창이 **어느 노드에서 몇 시에 시작했는지** 알려 줍니다.
- **쿨다운은 왜 있나요** — 너무 자주 도는 것을 막습니다. 다만 **크론 주기보다 길게 두면 매번 건너뛰므로** 저장이 거부됩니다.
- **오래된 기록이 안 지워집니다** — 파기 배치가 꺼져 있는지 확인하십시오. **기본이 꺼짐입니다.**
