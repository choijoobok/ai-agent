# 실행 이력

> 배치가 **언제 어떻게 돌았는지**를 봅니다. 실행 중인 것을 **중단 요청**할 수도 있습니다.

**메뉴 위치** 시스템 › 배치 › 실행 이력

[실행 이력 화면 — 결과와 소요 시간이 나란히 보입니다](./mockup.html#main)

---

## 1. 먼저 알아 둘 것

- **이 화면은 세 가지 질문에 답합니다.**

| 질문 | 어디를 보나 |
|---|---|
| *어제 안 돌았는데 왜?* | **줄이 아예 없으면 꺼져 있던 것**이고, *건너뜀* 줄이 있으면 **켜져 있는데 건너뛴 것**입니다 |
| *뭐가 오래 걸리나?* | `소요` 칸의 제목을 눌러 **정렬**합니다 |
| *왜 두 번 돌았나?* | `노드` 칸을 켜서 봅니다 — 같으면 재시도, **다르면 두 서버가 겹친 것** |

- **여기서는 기록을 고칠 수 없습니다.** 유일하게 할 수 있는 일이 **중단 요청**입니다.
- **[스케줄 관리]와 짝입니다.** 여기서 원인을 확인하고 거기서 고칩니다.
- **기록은 1년 남습니다.** 목록 아래에 그 안내가 있습니다.

---

## 2. 찾기

1. 조회조건에 값을 넣고 `[조회]`. 처음 열면 **최근 7일**이 들어 있습니다.

**자주 쓰는 조건**

| 이렇게 찾고 싶다 | 이렇게 넣습니다 |
|---|---|
| **잘못된 것만 전부** | `결과 묶음`을 *실패만* 으로 |
| **건너뛴 것만** | `결과 묶음`을 *건너뜀만* 으로 |
| 특정 배치의 이력 | `배치 ID`에 넣습니다 |
| **오래 걸린 것** | `소요 시간 이상`에 **초 단위**로 넣습니다 (10분이면 `600`) |
| 어느 서버에서 돌았나 | `노드`에 넣습니다 |
| 자동/수동 구분 | `실행 구분`을 고릅니다 |

- **`결과 묶음`과 `결과`는 다른 질문입니다.** 묶음은 *실패 전부* 이고 결과는 *이 코드만* 입니다. **실패가 한 종류가 아니라서** 묶음이 필요합니다 — *중단됨* 도 끝까지 못 간 실행이라 함께 봐야 합니다.
- **기간을 비울 수 있습니다.** 비우면 전체가 나오고 느려지지만 **막지는 않습니다.**
- **정렬이 됩니다** — `시작` 과 `소요` 두 칸. 다른 이력 화면과 다른 점입니다.
- `종료` · `노드` · `중단 요청` · `이력 ID` 칸은 숨어 있습니다 — 그리드 설정(`[⚙]`)에서 켭니다.

**결과 일곱 가지**

| 결과 | 무슨 뜻인가 | 무엇을 하나 |
|---|---|---|
| *실행 중* | 지금 돌고 있습니다 | 기다리거나 `[중단]` |
| *성공* | 정상적으로 끝났습니다 | — |
| **실패** | 오류로 끝났습니다 | **`[보기]` 로 오류 내용을 봅니다** |
| *건너뜀(락)* | **다른 서버가 이미 돌고 있었습니다** | **정상입니다** — 서버가 여럿일 때 생깁니다 |
| **건너뜀(쿨다운)** | **쿨다운 때문에 건너뛰었습니다** | **설정이 잘못됐을 수 있습니다** — [스케줄 관리]에서 확인 |
| *중단됨* | 중단 요청을 받아 멈췄습니다 | — |
| **유실** | **서버가 죽어 끝을 못 남겼습니다** | **그 서버에 무슨 일이 있었는지** 확인합니다 |

> **실패와 유실은 색이 같지만 하는 일이 다릅니다.** *실패* 는 **오류 내용**을 보고, *유실* 은 **서버 상태**를 봅니다.

---

## 3. 하기

### 3-1. 왜 실패했는지 보기

`[보기]` 를 누르거나 **줄을 두 번 누르면** 상세 창이 열립니다. **탭이 둘**입니다.

[상세 창 — 결과 상세와 오류 두 탭](./mockup.html#detail)

| 탭 | 무엇이 있나 |
|---|---|
| **결과 상세** | 무엇을 얼마나 처리했는지 |
| **오류** | 실패한 경우의 오류 내용 |

- **`[보기]` 가 없는 줄도 있습니다** — 남길 내용이 없었던 것입니다.
- 읽기만 하고 복사할 수 있습니다.

### 3-2. 안 돈 이유 찾기

**"어제 정산이 안 됐다"** 는 문의가 오면 순서가 이렇습니다.

1. `배치 ID`로 조회하고 기간을 그날로 맞춥니다.
2. **줄이 아예 없다** → 그날 **꺼져 있었거나 크론이 안 맞았습니다.** [스케줄 관리]에서 `사용` 과 `다음 실행` 을 확인합니다.
3. ***건너뜀(쿨다운)*** → **쿨다운 설정 문제**입니다. [스케줄 관리]에서 쿨다운을 줄입니다.
4. *건너뜀(락)* → 다른 서버가 돌고 있었습니다. **대개 정상**입니다.
5. *실패* → `[보기]` 로 오류를 봅니다.

> **줄이 없는 것과 *건너뜀* 은 다른 사건입니다.** 앞은 **아예 시작조차 안 한 것**이고, 뒤는 **시작하려다 멈춘 것**입니다.

### 3-3. 오래 걸리는 배치 찾기

1. `소요 시간 이상`에 초 단위로 넣습니다 (10분 = `600`).
2. `[조회]`.
3. `소요` 칸 제목을 눌러 **긴 것부터** 정렬합니다.

### 3-4. 두 번 돈 이유 찾기

1. 그리드 설정(`[⚙]`)에서 **`노드`** 칸을 켭니다.
2. 두 줄의 노드를 비교합니다.

| 노드가 | 무슨 뜻인가 |
|---|---|
| **같다** | 재시도했거나 누가 수동으로 한 번 더 돌렸습니다 — `실행 구분` 을 봅니다 |
| **다르다** | **두 서버가 겹쳐 시작했습니다** — 잠금이 제대로 안 걸린 것입니다 |

### 3-5. 실행 중인 배치 중단하기

1. *실행 중* 인 줄을 고릅니다. **여러 줄을 한 번에** 고를 수 있습니다.
2. `[중단]` 을 누릅니다.
3. 확인 창이 **요청까지만 한다**고 알려 줍니다.

> **바로 멈추지 않을 수 있습니다.** 배치가 다른 서버에서 돌고 있을 수 있어 **강제로 끊지 못합니다** — 배치가 스스로 확인하고 멈춥니다. 그래서 확인 창이 *"중단합니다"* 라고 하지 않습니다.

- 결과 창이 **요청한 건수**와 **이미 요청돼 있던 건수**를 **따로** 알려 줍니다 — 두 번 눌러도 **한 번만 먹습니다.**
- *실행 중* 이 아닌 줄이 섞여 있으면 **그 줄은 그냥 빠집니다** — 확인 창의 건수가 실제 대상 수입니다. 하나도 없으면 **버튼이 잠깁니다.**
- 실제로 멈추면 결과가 *중단됨* 으로 바뀝니다. **다시 조회해 확인하십시오.**
- `중단 요청` 칸을 켜면 **이미 요청했는지** 보입니다.

### 3-6. 엑셀로 받기

- `[⤓]` — 현재 페이지와 전체 중에서 고릅니다. **지금 보이는 컬럼만** 나갑니다.
- 엑셀 올리기는 이 화면에 없습니다.

## 4. 안 될 때

| 이런 일이 생기면 | 이유 | 어떻게 하나 |
|---|---|---|
| *실행 중인 이력이 아닙니다.* | 그 사이에 끝났습니다 | 다시 조회합니다 |
| *이미 파기된 이력입니다.* | 1년이 지나 지워졌습니다 | 다시 조회합니다 |
| **`[중단]` 이 잠겨 있습니다** | 고른 줄에 *실행 중* 이 하나도 없습니다 | *실행 중* 인 줄을 고릅니다 |
| **중단했는데 안 멈춥니다** | **강제로 끊을 수 없습니다** | 배치가 확인하는 지점까지 기다립니다. 오래 걸리면 개발 담당자에게 알립니다 |
| 배치명이 *(삭제된 배치)* 입니다 | **등록이 지워졌습니다.** 이력은 남습니다 | 정상입니다 |
| **1년 전 기록이 없습니다** | 보존 기간이 지났습니다 | 목록 아래 안내에 기간이 있습니다 |
| *실패한 배치가 없습니다* 라고 나옵니다 | **정말 없는 것입니다** | 빈 결과가 아니라 답입니다 |
| `[보기]` 가 없는 줄이 있습니다 | 남길 내용이 없었습니다 | 정상입니다 |
| 줄을 눌러도 선택이 안 됩니다 | **체크박스로만 선택합니다** | 왼쪽 체크박스를 씁니다 |
| `배치 ID` 를 고르는 목록이 없습니다 | 텍스트로 넣습니다 | 목록에서 셀을 복사해 붙입니다 — **지워진 배치도 찾을 수 있게** 하기 위해서입니다 |
| 조회가 아주 느립니다 | 기간을 비웠습니다 | 기간을 좁힙니다 |

## 5. 다른 메뉴와의 관계

**먼저 해야 하는 것**

| 무엇을 | 어디서 |
|---|---|
| 배치 등록 | **[스케줄 관리]** |

**여기서 저장하면 바뀌는 곳**

- **거의 없습니다.** 중단을 요청하면 그 사실만 기록되고, 실제로 멈추는 것은 배치가 정합니다.

**같이 보는 화면**

| 무엇이 궁금한가 | 어디로 |
|---|---|
| **왜 이렇게 도나 · 크론을 고치려면** | **[스케줄 관리]** — `배치 ID` 를 두 번 눌러 바로 갑니다 |
| 오래된 기록을 며칠 보관하나 | **[시스템 환경설정]** |

## 6. 자주 묻는 것

- **줄이 아예 없습니다** — 그날 **꺼져 있었거나 크론이 안 맞았습니다.** *건너뜀* 과 다른 사건입니다.
- **건너뜀이 계속 나옵니다** — *(락)* 이면 서버가 여럿이라 정상이고, ***(쿨다운)*** 이면 **설정을 고쳐야 합니다.**
- **중단을 눌렀는데 계속 돕니다** — 정상일 수 있습니다. 배치가 확인하는 지점에 닿아야 멈춥니다.
- ***유실* 은 뭔가요** — 배치가 도는 중에 **서버가 죽어** 끝을 기록하지 못한 것입니다. 실제로 끝났는지는 데이터를 확인해야 합니다.
- **왜 이 화면만 정렬이 되나요** — *뭐가 오래 걸리나* 가 이 화면의 주된 질문이고, 그것을 위해 소요 시간을 따로 저장하기 때문입니다.
- **1년 지난 기록이 그대로 있습니다** — 자동 정리 작업이 **꺼져 있을 수 있습니다.** [스케줄 관리]에서 확인하십시오.
