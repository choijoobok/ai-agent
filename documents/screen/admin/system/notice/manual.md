# 공지사항 관리

> **모든 사용자에게 보일 공지를 등록합니다.** 언제부터 언제까지 보일지, 로그인할 때 팝업으로 띄울지를 함께 정합니다.

**메뉴 위치** 시스템 › 공지 › 공지사항 관리 (`/admin/system/notice`)

[공지사항 관리 화면 — 게시 기간과 상태가 나란히 보입니다](./mockup.html#main)

---

## 1. 먼저 알아 둘 것

- **여기서 올린 글은 전 사용자가 봅니다.** 팝업을 켜면 **로그인하자마자 화면 가운데에** 뜹니다. 올리기 전에 내용을 꼭 확인하십시오.
- **끄는 것과 기간을 정하는 것은 다른 일입니다.**

| 무엇을 하려면 | 어떻게 |
|---|---|
| **미리 만들어 두고 나중에 보이게** | `게시 시작`을 미래 날짜로 넣습니다 |
| **정해진 날까지만 보이게** | `게시 종료`를 넣습니다 |
| **지금 당장 내리기** | `사용`을 **끕니다** — 기간은 그대로 둡니다 |

> **`사용` 을 끄면 기간과 상관없이 즉시 사라집니다.** 급히 내려야 할 때는 기간을 고치지 말고 **끄십시오** — 기간을 고치면 애써 정해 둔 게시 계획이 사라집니다.

- **`게시 상태` 칸이 지금 어떤 상태인지 말해 줍니다.** 저장한 뒤 이 칸을 확인하는 것이 가장 확실합니다.

---

## 2. 찾기

1. 조회조건에 값을 넣고 `[조회]`.

**자주 쓰는 조건**

| 이렇게 찾고 싶다 | 이렇게 넣습니다 |
|---|---|
| **지금 사용자에게 보이는 것만** | `게시 상태`에서 *게시중* 하나만 고릅니다 |
| **곧 올라갈 것** | *예정* 을 고릅니다 |
| **내려 둔 것도 함께** | `게시 상태`를 **비웁니다** |
| 팝업으로 뜨는 것만 | `팝업`을 *사용* 으로 고릅니다 |

- **처음에는 *내림* 을 뺀 셋이 골라져 있습니다.** 내려 둔 공지는 안 보이는 것이 정상이라 목록의 기본에서도 빠집니다 — **감추는 것이 아니라 기본값**이고, **비우면 전부 나옵니다.**
- **`게시 기간`은 비어 있습니다.** 비워 두면 기간 제한 없이 전부 나옵니다 — 지난달에 올린 공지도 보여야 하기 때문입니다.
- **본문으로는 찾을 수 없습니다.** 제목으로 찾으십시오.
- `공지 ID` · `팝업 시작` · `팝업 종료` 칸은 숨어 있습니다 — 그리드 설정(`[⚙]`)에서 켭니다.

**`게시 상태` 넷**

| 상태 | 무슨 뜻인가 |
|---|---|
| *예정* | 아직 시작일이 안 됐습니다 |
| *게시중* | **지금 사용자에게 보입니다** |
| *종료* | 종료일이 지났습니다 |
| *내림* | **`사용` 을 껐습니다** |

> *종료* 와 *내림* 은 색이 같습니다. **둘 다 지금 안 보인다**는 점은 같고, 다른 것은 *왜* 입니다.

---

## 3. 하기

### 3-1. 공지 올리기

1. `[행 추가]`.
2. **제목**과 **본문**을 채웁니다. 본문은 칸을 **두 번 눌러 펼쳐서** 씁니다.
3. **`게시 시작` 을 넣습니다. 필수입니다.**
   - 지금부터 보이게 하려면 **현재 시각**을 넣습니다.
   - 나중에 보이게 하려면 **미래 시각**을 넣습니다 — 그때가 되면 자동으로 올라갑니다.
   - **비워 두고 저장할 수 없습니다.** 언제부터인지 반드시 정해야 하기 때문입니다.
4. 끝나는 날이 있으면 `게시 종료`를 넣습니다. **비우면 계속 보입니다.**
5. `[저장]`.
6. **`게시 상태` 칸을 확인합니다** — *게시중* 이면 지금 보이는 것이고 *예정* 이면 나중에 올라갑니다.

- **`사용` 은 켜진 채로 만들어집니다.** 만들자마자 내려가 있으면 왜 안 보이는지 찾게 되기 때문입니다.
- **`팝업` 은 꺼진 채로 시작합니다.** 켜는 것은 직접 해야 합니다 — 전 사용자에게 뜨기 때문입니다.
- `정렬` 숫자가 작을수록 **위에** 옵니다.

### 3-2. 팝업으로 띄우기

1. `팝업` 스위치를 켭니다.
2. 그리드 설정(`[⚙]`)에서 **`팝업 시작` · `팝업 종료`** 칸을 켭니다.
3. 두 날짜를 넣습니다. **팝업을 켜면 필수입니다.**
4. `[저장]`.

> **팝업 기간은 게시 기간 안에 있어야 합니다.** 벗어나면 저장이 거부됩니다 — **목록에 없는 공지가 팝업으로 뜨는 일**을 막기 위해서입니다.

- 팝업은 **정렬 순서의 첫 번째 것 하나**가 뜹니다.
- 사용자는 **다음 로그인부터** 봅니다.

### 3-3. 공지 내리기

**`사용` 스위치를 끄고 `[저장]`** — 그것이 전부입니다.

- 그 자리에서 사용자 화면에서 사라집니다.
- **기간은 그대로 남아 있으므로** 다시 켜면 원래 계획대로 돌아갑니다.
- 상태가 *내림* 으로 바뀝니다.

### 3-4. 공지 지우기

줄을 고르고 `[행 삭제]` → `[저장]`. **여러 줄을 한 번에 고를 수 있습니다.**

[지울 공지의 제목을 하나씩 보여 줍니다](./mockup.html#delete)

저장 전에 **지울 공지의 제목을 하나씩 보여 주고** 물어봅니다.

> **되돌릴 수 없습니다.** 잠깐 안 보이게 하려는 것이면 **`사용` 을 끄십시오.** 대부분의 경우 그것이 맞습니다.

### 3-5. 엑셀

이 화면에는 **엑셀이 없습니다.** 본문이 길어 엑셀 칸에 다 들어가지 않고, **잘린 공지 파일은 원본도 참고 자료도 못 되기** 때문입니다.

## 4. 안 될 때

| 이런 일이 생기면 | 이유 | 어떻게 하나 |
|---|---|---|
| *제목·본문·게시 시작은 필수입니다.* | 셋 중 하나가 비었습니다 | 채웁니다. 특히 **`게시 시작`을 잊기 쉽습니다** |
| *게시 종료가 시작보다 앞입니다.* | 날짜가 뒤집혔습니다 | 바로잡습니다 |
| *팝업을 켜면 팝업 기간은 필수입니다.* | 팝업만 켜고 날짜를 안 넣었습니다 | 그리드 설정에서 팝업 날짜 칸을 켜고 채웁니다 |
| ***팝업 기간이 게시 기간을 벗어납니다.*** | 팝업이 게시보다 넓거나 어긋납니다 | **팝업 기간을 게시 기간 안으로** 맞춥니다 |
| *없는 공지입니다.* | 다른 사람이 먼저 지웠습니다 | 다시 조회합니다 |
| **올렸는데 사용자에게 안 보입니다** | ① `사용`이 꺼져 있거나 ② 아직 시작 전이거나 ③ 이미 끝났습니다 | **`게시 상태` 칸을 보십시오** — 셋 중 무엇인지 말해 줍니다 |
| **팝업이 안 뜹니다** | 팝업 기간 밖이거나, 사용자가 **아직 다시 로그인하지 않았습니다** | 팝업 날짜 칸을 켜서 확인합니다 |
| *조회된 공지가 없습니다* 라고 나옵니다 | 상태를 *게시중* 으로만 걸었다면 **정말 아무 공지도 안 보이는 것**입니다 | 빈 결과가 아니라 답입니다 |
| 지난달 공지가 안 보입니다 | 기간 조건이 걸려 있습니다 | `게시 기간`을 비우고 조회합니다 |
| 내려 둔 공지가 안 보입니다 | `게시 상태` 기본값에서 빠져 있습니다 | *내림* 을 함께 고르거나 조건을 비웁니다 |
| 본문으로 검색이 안 됩니다 | 지원하지 않습니다 | 제목으로 찾습니다 |
| `게시 상태` 칸이 안 고쳐집니다 | 시스템이 계산하는 값입니다 | `사용`과 기간을 고치면 따라 바뀝니다 |
| 컬럼 제목을 눌러도 정렬이 안 됩니다 | 제목·본문·사용은 정렬이 열려 있지 않습니다 | 정렬 숫자나 게시 시작으로 정렬합니다 |

---

## 5. 다른 메뉴와의 관계

**먼저 해야 하는 것**

- 없습니다.

**여기서 저장하면 바뀌는 곳**

| 어디가 | 어떻게 |
|---|---|
| **모든 사용자의 알림 창** | 게시중인 공지가 공지 탭에 나옵니다 |
| **로그인 직후 팝업** | 팝업을 켰고 기간 안이면 **다음 로그인부터** 뜹니다 |

**같이 보는 화면**

- 특별히 없습니다. 공지는 다른 자료와 연결되지 않습니다.

---

## 6. 자주 묻는 것

- **급히 내려야 합니다** — `사용`을 끄고 저장하십시오. 기간은 건드리지 마십시오.
- **지금 뜨는 팝업을 바로 없애고 싶습니다** — `팝업`을 끄거나 `사용`을 끕니다. 다만 **이미 팝업을 본 사람에게는 이미 뜬 뒤**입니다.
- **예약해 둘 수 있나요** — 됩니다. `게시 시작`을 미래로 넣으면 그때 자동으로 올라갑니다.
- **한 번 본 사람에게 또 뜨나요** — 팝업의 다시보지않기 동작은 사용자 쪽 설정입니다. 이 화면에서 정하지 않습니다.
- **여러 개를 팝업으로 띄우고 싶습니다** — 팝업은 **정렬 순서의 첫 건 하나**만 뜹니다. 순서를 정렬 숫자로 조정하십시오.
- **잘못 올린 글을 지웠는데 복구하고 싶습니다** — 되돌릴 수 없습니다. 그래서 **끄기를 먼저 권합니다.**
