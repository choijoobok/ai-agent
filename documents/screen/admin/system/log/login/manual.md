# 로그인 이력

> 누가 언제 로그인했는지, **왜 로그인하지 못했는지**, 그리고 언제 어떻게 접속이 끊겼는지를 보여 줍니다. *로그인이 안 된다* 는 문의가 오면 **여기부터** 봅니다.

**메뉴 위치** 시스템 › 로그 › 로그인 이력

[로그인 이력 화면 — 결과 묶음을 *실패만* 으로 두고 보는 것이 기본 동선입니다](./mockup.html#main)

---

## 1. 먼저 알아 둘 것

- **이름은 *로그인 이력* 이지만 로그아웃과 접속 종료까지 함께 남습니다.** 정상 로그아웃, 오래 안 써서 끊긴 것, 관리자가 끊은 것, 다른 곳에서 로그인해 밀려난 것이 모두 한 줄입니다.
- **없는 아이디로의 시도도 남습니다.** 등록되지 않은 아이디를 넣어 본 기록이 그대로 보입니다 — 이 화면의 두 번째 쓸모가 그것입니다.
- **조회 기간은 반드시 넣어야 하고, 한 번에 92일까지만** 볼 수 있습니다. 기록 자체는 **1년** 남습니다.
- **여기서는 보기만 합니다.** 계정을 풀거나 고치는 것은 [사용자 관리]입니다.

---

## 2. 찾기

1. `조회 기간`을 넣습니다. **비워 둘 수 없습니다.** 처음 열면 최근 7일이 들어 있습니다.
2. 조건을 더 넣고 `[조회]`.

**자주 쓰는 조건**

| 이렇게 찾고 싶다 | 이렇게 넣습니다 |
|---|---|
| **못 들어온 것만 전부** | `결과 묶음`을 *실패만* 으로 고릅니다 — 가장 많이 쓰는 조건입니다 |
| 접속이 끊긴 사건만 | `결과 묶음`을 *종료만* 으로 고릅니다 |
| 비밀번호를 틀린 것만 | `결과`에서 *비밀번호 불일치* 를 고릅니다 |
| 한 사람의 기록 | `사용자 아이디`에 아이디를 넣습니다 |
| 이름 일부만 기억날 때 | `사용자명`에 조각을 넣습니다 (기본이 *포함* 입니다) |
| **수상한 접속을 쫓을 때** | 실패한 줄에서 IP 를 복사해 `접속 IP`에 넣고 다시 조회합니다 |
| 사용자가 오류 번호를 들고 왔을 때 | `추적 ID`에 그대로 붙여 넣습니다 — **이때는 기간을 넣지 않아도 됩니다** |

- **`결과 묶음`과 `결과`를 함께 채우면 둘 다 만족하는 것만** 나옵니다. *실패만* + *비밀번호 불일치* 는 결국 비밀번호 실패입니다.
- `결과 묶음`에는 *성공만* 이 없습니다. 성공은 한 가지뿐이라 `결과`에서 *성공* 을 고르면 됩니다.
- **`사용자명`으로 찾으면 없는 아이디로의 시도는 빠집니다.** 그 줄에는 이름이 없기 때문입니다 — 그런 시도를 찾을 때는 `사용자 아이디`나 `결과`를 씁니다.
- `접속 IP`는 **정확히 일치**해야 합니다. 앞자리만 넣는 방식은 지원하지 않습니다.
- **정렬은 `일시` 하나만** 됩니다. 목록 아래는 `‹ 이전` · `다음 ›` 뿐이고 전체 건수와 페이지 번호는 없습니다.

## 3. 하기

### 3-1. 왜 못 들어왔는지 읽기

`결과` 칸이 사유를 말합니다. **색은 셋뿐입니다.**

| 색 | 무슨 뜻인가 |
|---|---|
| 초록 | 로그인 성공 |
| 빨강 | **못 들어왔다** — 사유는 칸의 글자가 말합니다 |
| 회색 | **접속이 끝났다** — 로그아웃·만료·강제 종료·밀려남. **장애가 아닙니다** |

사용자가 *"갑자기 로그아웃됐다"* 고 하면 회색 줄입니다 — 정상 동작입니다.

**빨강일 때 무엇을 하나**

| 결과 | 무슨 일인가 | 어디서 푸나 |
|---|---|---|
| *존재하지 않는 ID* | 그런 아이디가 없습니다 | 오타이거나, 계정이 아직 없습니다 |
| *비밀번호 불일치* | 비밀번호가 틀렸습니다 | 반복되면 [사용자 관리]에서 `[비밀번호 초기화]` |
| *사용 중지 계정* | 관리자가 계정을 껐습니다 | [사용자 관리]에서 `사용 여부`를 켭니다 |
| *사용 기간 만료* | 사용 종료일이 지났습니다 | [사용자 관리]에서 기간을 늘립니다 |
| *잠긴 계정* | 여러 번 틀려 잠겼습니다 | [사용자 관리]에서 `[잠금 해제]` |
| *휴면 계정* | 오래 안 들어왔습니다 | [사용자 관리]에서 `[휴면 해제]` |
| *허용 IP 가 아니다* | 등록된 대역 밖에서 접속했습니다 | [사용자 관리]의 [접속 IP] 탭 |
| *유효 권한이 공집합이다* | 열 수 있는 메뉴가 하나도 없습니다 | [역할별 권한] 또는 [개인 예외 권한] |
| *임시 비밀번호가 유효 시간을 넘겼다* | 발급받고 너무 늦게 들어왔습니다 | 다시 초기화해 발급합니다 |
| *기존 세션이 살아 있어 거부됐다* | 이미 다른 곳에서 접속 중입니다 | [사용자 관리]의 [활성 세션] 탭에서 끊습니다 |

> **사유가 여럿일 수 있습니다.** 이 칸은 **먼저 걸린 것 하나**만 보여 줍니다 — 잠금을 풀어도 여전히 못 들어오면 휴면이나 사용 중지가 남아 있는 것입니다.

### 3-2. 없는 계정으로의 시도 살펴보기

`사용자명` 칸에 **`없는 계정`** 이라는 빨간 표시가 붙은 줄이 그것입니다.

- 표시의 글자와 색은 `결과` 칸의 *존재하지 않는 ID* 와 **같은 것**입니다 — 한 줄의 두 칸이 같은 말을 합니다.
- **지금은 없는 계정이라는 뜻**이므로, 예전에 있다가 지워진 계정의 로그인에도 같은 표시가 붙습니다.
- `root` · `admin` · `test` 같은 아이디로의 시도가 **짧은 시간에 여러 줄** 보이면 그 IP 를 복사해 `접속 IP`로 다시 조회합니다. 같은 곳에서 얼마나 두드렸는지가 한눈에 보입니다.
- `사용자 아이디`가 *(입력 없음)* 인 줄은 아이디조차 넣지 않은 것입니다 — *없는 계정* 과는 다릅니다.

### 3-3. 어떤 기기에서 들어왔는지 보기

`브라우저` 칸은 **숨어 있습니다.** 그리드 설정(`[⚙]`)에서 켜면 보이고, 칸에 마우스를 올리면 전체가 뜹니다.

- 한 줄이 아주 길어 켜면 다른 칸이 밀립니다. 기기를 확인할 때만 켜십시오.
- 값은 있는 그대로입니다 — *Chrome / Windows* 처럼 정리해 주지는 않습니다.
- 쓸모는 하나입니다: **같은 사람이 평소와 다른 기기에서 들어왔나** 를 눈으로 비교하는 것.

### 3-4. 엑셀로 받기

- `[⤓]` — 현재 페이지와 전체 중에서 고릅니다. **지금 보이는 컬럼만** 나갑니다.
- **1년치가 필요하면 기간을 나눠 네 번 받습니다.** 한 번에는 92일까지입니다.
- 엑셀 올리기는 이 화면에 없습니다.

## 4. 안 될 때

| 이런 일이 생기면 | 이유 | 어떻게 하나 |
|---|---|---|
| *조회 기간은 필수입니다.* | 기간을 비웠습니다 | 기간을 넣습니다. 요청 번호를 알면 `추적 ID`만으로도 찾을 수 있습니다 |
| *조회 기간이 허용 범위를 넘었습니다.* | 92일이 넘습니다 | 나눠서 조회합니다 |
| *조회된 실패가 없습니다* 라고 나옵니다 | **실패가 정말 없는 것입니다** | 이것은 빈 결과가 아니라 답입니다 — 사용자가 아예 시도하지 않았을 수 있습니다 |
| 사용자가 실패했다는데 안 보입니다 | 아이디를 다르게 넣었거나, 기간이 어긋났습니다 | `사용자 아이디`를 비우고 IP 나 기간으로만 조회해 봅니다 |
| `사용자명`이 비어 있고 표시도 없습니다 | 아이디 자체가 입력되지 않은 시도입니다 | 정상입니다 |
| 회색 줄이 많습니다 | 로그아웃·세션 만료입니다 | **장애가 아닙니다.** 실패만 보려면 `결과 묶음`을 *실패만* 으로 두십시오 |
| 1년 전 기록이 안 보입니다 | 한 번에 92일까지만 조회됩니다 | 그 기간을 직접 지정해 조회합니다 |
| 컬럼 제목을 눌러도 정렬되지 않습니다 | `일시` 말고는 정렬이 열려 있지 않습니다 | 조회조건으로 거릅니다 |
| 메뉴가 보이지 않습니다 | 이 메뉴 권한이 없습니다 | [역할별 권한] 담당자에게 요청합니다 |

## 5. 다른 메뉴와의 관계

**먼저 해야 하는 것**

- 없습니다. 로그인을 시도하면 자동으로 쌓입니다.

**여기서 저장하면 바뀌는 곳**

- 없습니다. **이 화면은 아무것도 바꾸지 않습니다.** 계정을 실제로 푸는 것은 [사용자 관리]입니다.

**같이 보는 화면**

| 무엇이 궁금한가 | 어디로 |
|---|---|
| 이 계정을 어떻게 푸나 | **[사용자 관리]** — 잠금·휴면·사용 여부·사용 기간·접속 IP 를 모두 여기서 다룹니다 |
| 지금 접속 중인 사람을 끊고 싶다 | **[사용자 관리]** 의 [활성 세션] 탭. 그 탭의 `접속 IP` · `브라우저` 는 **이 화면의 기록에서 찾아 붙인 값**입니다 |
| 들어온 뒤 무엇을 했나 | **[사용 이력]** — 같은 `추적 ID` 로 이어집니다 |
| 권한이 하나도 없다는 실패 | **[역할별 권한]** · **[개인 예외 권한]** |

## 6. 자주 묻는 것

- **로그인은 됐는데 메뉴가 안 보인다고 합니다** — 로그인 자체는 성공이므로 이 화면에는 초록 줄입니다. 권한 문제이니 [사용자 관리]의 [유효 권한] 탭을 보십시오.
- **회색 *세션 만료* 는 언제 기록되나요** — 세션이 끊긴 그 순간이 아니라 **끊긴 뒤 처음 무언가를 눌렀을 때**입니다. 그래서 시각이 사용자가 느낀 것보다 늦을 수 있습니다.
- **밀려났다는 게 무슨 뜻인가요** — 같은 계정으로 다른 곳에서 로그인해서 먼저 있던 접속이 끊긴 것입니다. 계정을 함께 쓰고 있다는 신호입니다.
- **전체가 몇 건인지 알고 싶습니다** — 이 화면은 세지 않습니다. 엑셀로 받아 세는 것이 정확합니다.
- **오래된 기록이 지워지나요** — 1년까지 남도록 되어 있습니다. 다만 자동 파기는 **켜야 도는 기능**이라, 켜지 않았다면 그대로 쌓입니다.
