# 공통 코드 관리

> 화면 곳곳의 선택 상자에 나오는 **항목들**을 등록하고 고칩니다. *주문 유형* · *처리 상태* 처럼 값이 정해져 있는 것들이 모두 여기서 나옵니다.

**메뉴 위치** 시스템 › 기준정보 › 공통 코드 관리

[공통 코드 관리 화면 — 위는 코드 그룹, 아래는 그 그룹의 코드들](./mockup.html#main)

---

## 1. 먼저 알아 둘 것

- **구조는 두 단입니다.** 위쪽이 **그룹**(*주문 유형* 같은 묶음), 아래쪽이 그 그룹의 **코드**(*B2B* · *B2C* 같은 항목)입니다.
- **그룹은 함부로 만들지 않습니다.** 그룹 이름은 **프로그램이 직접 부르는 것**이라, 개발에서 정해 준 이름이 아니면 만들어도 아무 화면에서도 쓰이지 않습니다. 여기서 주로 하는 일은 **이미 있는 그룹에 코드를 더하거나 고치는 것**입니다.
- **`시스템` 표시가 붙은 줄은 지울 수도 끌 수도 없습니다.** 프로그램이 그 값에 기대어 동작하기 때문입니다.
- **여기서 고치면 다른 사람 화면에도 곧 반영됩니다.** 선택 상자의 항목과 글자가 함께 바뀝니다.
- **코드명은 지금 쓰고 있는 언어로만 입력됩니다.** 다른 언어는 [다국어 메시지 관리]에서 채웁니다.

---

## 2. 찾기

1. 위쪽 조회조건에 값을 넣고 `[조회]`.
2. 위쪽 목록에서 **그룹 한 줄을 고르면** 아래에 그 그룹의 코드가 나옵니다.

**자주 쓰는 조건**

| 이렇게 찾고 싶다 | 이렇게 넣습니다 |
|---|---|
| 그룹 이름을 알 때 | `그룹명`에 조각을 넣습니다 |
| **이 코드값이 어느 그룹에 있는지 모를 때** | `코드`에 그 값을 넣습니다 — **그 값을 가진 그룹만** 위에 나옵니다 |
| 화면에 보이던 그 글자로 찾을 때 | `코드명`에 그 글자를 넣습니다 |

- **아래 두 조건(`코드` · `코드명`)은 위아래를 함께 거릅니다.** 그룹을 고르면 아래 목록이 **이미 그 조건으로 걸려 있습니다** — 전체를 보려면 조건을 지우고 다시 조회하십시오.
- `사용 여부`나 `시스템 여부`로는 조회할 수 없습니다. **컬럼 제목의 필터**로 거르십시오 — 위아래 어느 쪽을 거르는지가 자리로 분명해집니다.
- 참조 속성 값으로도 조회할 수 없습니다. 아래 목록은 **전체가 한 번에** 나오므로 컬럼 필터로 충분합니다.

---

## 3. 하기

### 3-1. 코드 더하기 (가장 흔한 일)

1. 위에서 그룹을 고릅니다.
2. 아래 그리드에서 `[행 추가]`.
3. **코드**와 **코드명**을 채웁니다.
   - **코드는 나중에 바꿀 수 없습니다.** 고치려면 지우고 다시 만듭니다.
   - `정렬`은 **선택 상자에 나오는 순서**입니다. 관리 화면용이 아닙니다.
4. `[저장]`.

### 3-2. 코드 끄기 · 지우기

- **쓰지 않게 된 코드는 `사용`을 끕니다.** 그러면 **앞으로는 선택 상자에 나오지 않지만**, 이미 그 값으로 저장된 기존 자료는 그대로 남습니다.
- 지우는 것은 `[행 삭제]` → `[저장]` 입니다. **참조 속성 값이 있으면 저장 전에 몇 건이 함께 사라지는지 알려 줍니다.**
- **`시스템` 표시가 붙은 줄은 체크박스 자체가 없고, `사용`도 끌 수 없습니다.**

> **끄는 것과 지우는 것은 다릅니다.** 지우면 그 코드가 무엇이었는지가 사라져, 예전 자료의 그 값이 이름 없는 값이 됩니다. **웬만하면 끄십시오.**

### 3-3. 그룹 만들기

1. 위쪽에서 `[행 추가]` → `그룹 코드` · `그룹명`을 채우고 `[저장]`.
2. **저장하기 전에는 아래가 잠깁니다.** 먼저 저장하고, 그 줄을 다시 골라야 코드를 넣을 수 있습니다.

- **그룹 코드도 나중에 바꿀 수 없습니다.**
- 그룹에는 `사용` 스위치가 없습니다 — 그룹을 끈다는 것의 뜻이 정해져 있지 않기 때문입니다. 쓰지 않을 그룹은 **코드를 모두 지운 뒤 그룹을 지웁니다.**

### 3-4. 그룹 지우기

- **코드가 하나라도 남아 있으면 체크박스가 꺼집니다.** 칸에 마우스를 올리면 몇 건이 남았는지 알려 줍니다.
- 코드를 먼저 모두 지운 뒤 그룹을 지웁니다.

### 3-5. 참조 속성 — 코드마다 붙는 부가 값

어떤 그룹은 코드마다 **추가로 적어 둘 값**이 필요합니다. 그것을 참조 속성이라고 합니다.

[참조 코드 정의 창 — 이 그룹이 어떤 속성을 쓰는지 정합니다](./mockup.html#ref-def)

**두 단계입니다.**

1. **어떤 속성을 쓸지 정합니다** — 아래 그리드 위의 `[참조 코드 관리]` 를 누릅니다.
   - `참조 코드`는 **미리 허용된 것 중에서만** 고를 수 있습니다.
   - `참조명`에 적은 글자가 **아래 그리드의 컬럼 제목**이 됩니다. 같은 속성을 그룹마다 다르게 부를 수 있습니다.
   - 저장하고 창을 닫습니다.
2. **값을 채웁니다** — 아래 그리드의 **오른쪽 끝**에 방금 정한 컬럼이 생겼습니다. 칸에 값을 넣고 `[저장]`.

- **빈 칸이 곧 할 일입니다.** 아직 안 채운 코드가 한눈에 보이도록 일부러 펼쳐 두었습니다.
- **`시스템` 코드에도 참조값은 넣을 수 있습니다.** 보호되는 것은 코드의 존재이지 이 값이 아닙니다.
- 값을 **지우려면 칸을 비우고 저장**합니다.
- **정의를 지우면 그 컬럼에 넣었던 값이 모두 사라집니다.** 저장 전에 몇 건인지 알려 줍니다.

### 3-6. 다른 언어의 이름 채우기

- 이 화면의 `코드명`은 **지금 보고 있는 언어**의 이름입니다.
- 다른 언어는 **[다국어 메시지 관리]** 에서 채웁니다.
- **코드명 칸을 비우고 저장하면 그 언어의 이름을 지웁니다.** 그러면 화면에 `code.그룹.코드` 같은 글자가 그대로 보이는데, 그것이 *아직 안 채웠다* 는 표시입니다.

### 3-7. 엑셀로 받기

- `[⤓]` — 현재 페이지와 전체 중에서 고릅니다. **지금 보이는 컬럼만** 나갑니다.
- 엑셀 올리기는 이 화면에 없습니다.

## 4. 안 될 때

| 이런 일이 생기면 | 이유 | 어떻게 하나 |
|---|---|---|
| *이미 있는 코드 그룹입니다.* / *이미 있는 코드입니다.* | 같은 값이 이미 있습니다 | 조건을 비우고 그 값으로 조회해 확인합니다 |
| 같은 값이 두 번 있다는 표시가 뜹니다 | 지금 저장하려는 줄 안에 같은 값이 둘입니다 | 한 줄을 지웁니다 |
| 저장이 안 되고 **표**가 뜹니다 | 고칠 곳이 여럿입니다 — `컬럼 · 값 · 사유` 를 줄마다 보여 줍니다 | 표에 적힌 칸이 **붉게** 표시돼 있습니다. 하나씩 고치고 다시 저장합니다 |
| *다른 사용자가 먼저 저장했습니다* | 내가 화면을 연 뒤에 누군가 같은 코드를 먼저 넣었습니다 | **다시 조회**한 뒤 넣습니다 |
| *코드가 있어 그룹을 지울 수 없습니다.* | 그 그룹에 코드가 남아 있습니다 | 코드를 먼저 지웁니다 |
| *시스템 코드는 지우거나 끌 수 없습니다.* | 프로그램이 기대는 값입니다 | 지울 수 없습니다. 개발 담당자와 상의하십시오 |
| *허용되지 않은 참조 코드 값입니다.* | 미리 허용된 목록에 없는 값입니다 | 목록에서 고릅니다. 새 속성이 필요하면 개발 담당자에게 요청합니다 |
| *이 그룹에 정의되지 않은 참조 코드입니다.* | 정의가 지워진 뒤 옛 화면에서 저장했습니다 | 화면을 다시 조회합니다 |
| *이미 삭제된 코드 그룹입니다.* / *이미 삭제된 코드입니다.* | 다른 사람이 먼저 지웠습니다 | 다시 조회합니다 |
| *필수 값이 비어 있습니다.* | `그룹명` 또는 `참조명`이 비었습니다 | 채웁니다 |
| **아래 그리드가 눌리지 않습니다** | 그룹을 고르지 않았거나, 아직 저장하지 않은 새 그룹입니다 | 먼저 저장하고 그 줄을 다시 고릅니다 |
| **`[참조 코드 관리]` 가 눌리지 않습니다** | 그룹을 고르지 않았거나, **아래에 저장하지 않은 변경이 있습니다** | 눌러 보면 사유가 뜹니다. 저장하거나 되돌린 뒤 다시 누릅니다 |
| 다른 그룹을 골랐더니 물어봅니다 | 아래에 저장하지 않은 변경이 있습니다 | 버릴 것인지 답합니다. **아니오** 를 고르면 선택이 되돌아갑니다 |
| 화면에 `code.무엇.무엇` 같은 글자가 보입니다 | **그 언어의 코드명이 비어 있습니다** | 이 화면에서 코드명을 채우거나, 다른 언어면 [다국어 메시지 관리]에서 채웁니다 |
| 코드를 만들었는데 선택 상자에 안 나옵니다 | `사용`이 꺼져 있거나, 화면을 다시 열지 않았습니다 | `사용`을 켜고, 그 화면을 다시 엽니다 |

## 5. 다른 메뉴와의 관계

**먼저 해야 하는 것**

| 무엇을 | 어디서 | 왜 |
|---|---|---|
| 그룹 이름 정하기 | **개발** | 그룹 이름은 프로그램이 직접 부릅니다. 임의로 만든 그룹은 아무 화면에도 나오지 않습니다 |
| 참조 코드 허용 목록에 추가 | **이 화면** | `CODE_REF_KEY` 그룹을 골라 코드를 더하면 참조 코드 후보가 늘어납니다 |

**여기서 저장하면 바뀌는 곳**

| 어디가 | 어떻게 |
|---|---|
| **그 코드를 쓰는 모든 화면** | 선택 상자의 항목과 순서, 표시되는 글자가 바뀝니다 |
| 목록의 배지·상태 글자 | 같은 이름을 씁니다 — 예를 들어 [로그인 이력]의 결과 이름이 여기서 옵니다 |
| 조회조건의 선택 상자 | 마찬가지입니다 |

**같이 보는 화면**

- **[다국어 메시지 관리]** — 다른 언어의 코드명. 여기서 넣은 이름과 **같은 것**을 다루므로, 한쪽에서 지우면 다른 쪽에서도 사라집니다.

---

## 6. 자주 묻는 것

- **새 그룹을 만들었는데 아무 화면에도 안 나옵니다** — 그룹 이름은 프로그램이 부르는 것입니다. 개발에서 그 이름을 쓰도록 만들어야 나옵니다.
- **코드를 지웠더니 예전 자료가 이상해졌습니다** — 지우지 말고 **끄십시오.** 이미 저장된 값은 남는데 그 이름이 사라져서 그렇습니다.
- **순서를 바꾸고 싶습니다** — `정렬` 숫자를 고칩니다. 작은 값이 앞에 옵니다.
- **참조 속성이 뭔가요** — 코드마다 붙는 부가 값입니다. 예를 들어 *주문 유형* 마다 *약칭* 이나 *색상* 을 적어 두는 식입니다. 무엇에 쓰이는지는 그 값을 읽는 화면이 정합니다.
- **`시스템` 표시를 떼고 싶습니다** — 화면에 그 수단이 없습니다. 개발 담당자와 상의하십시오.
