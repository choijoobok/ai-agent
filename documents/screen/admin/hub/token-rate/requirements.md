# 요건 정의서 — 토큰 풀 기준 단가

## 개요

- **무엇을 하는 화면인가**: 월별 USD/100만 토큰 기준 단가를 산정하고, 해당 월의 턴 가정 또는 당월 실적 스냅샷·단가·수량·관리자 확정 근거를 확인한다.
- **프로세스상 위치**: SCR-015 모델 조합/소스 용도 확인 → 수동 턴 가정 또는 당월 실적 초안 → USD 기준 단가 검토·확정 → SCR-021에서 월 환산율·수동 보정률과 월 풀 확정.
- **이 데이터를 누가 쓰나**: 다음 달 토큰 풀 계획 담당자. 확정 단가만 월 계획에 인계한다.
- **바꾸면 어디가 흔들리나**: 미확정 대상 월의 USD 기준 단가와 다음 달 풀 미리보기. 과거 확정 단가·배정·사용량은 소급 변경하지 않는다.

## 1. 화면 구성

상단은 년월과 기준 단가(USD/100만 토큰) 두 업무 컬럼으로 간단히 표시한다. 월을 클릭하면 하단의 같은 월 산정 항목·실적 스냅샷·요약·근거로 바뀐다. 예시 초기 선택은 2026-11 작성중이며 2026-10·09는 확정된 당시 값이다. 작성중 수치는 미리보기이며 운영 적용값으로 사용하지 않는다.

목록 연동: 년월
대상 편집 조건: 확정 여부=N
선택 무관 버튼: 다음 달 초안 생성
산정 확정 버튼: 단가 확정
행 추가 탭: 산정 항목
상태별 버튼: 허용 목록

## 6. 규칙 — 저장 · 실행

### 6-1. 산식과 집계

산식·미상 처리·용도/귀속·스냅샷·확정 경계는 [REQ-613.calculation_contract](../../../../spec/10-requirements/013-reference-operations.yaml)가 정본이다.

- 수동 턴 가정과 당월 실적 월 합계를 같은 산식으로 계산한다. 월 합계를 용도별 서로 다른 호출수/턴수로 나눠 구성비를 바꾸지 않는다.
- 입력에 캐시가 포함되면 비캐시 입력을 분리한다. 캐시 세부 과금 단위의 비용과 쿼터 토큰 중첩을 구분하며 미지원/미상 단위는 보완 전 확정하지 않는다. 추론량이 출력에 포함되면 중복 가산하지 않는다.
- 실제 계량의 현재 유효값을 스냅샷 상한 시각까지 합산한다. 동일 실행 누적 재수신 중복을 제거하고 실패/중단/재시도/대체의 실제 소비는 남긴다. 현재 용도 미지정 모델의 사용자 주 추론·질의 임베딩 등 사용자 귀속 개인 쿼터 차감 대상은 모두 포함하며 시스템 운영/지식 재임베딩은 분리한다.
- USD 가격은 출처·확인일과 함께 관리한다. 동일 공급 경로/모델/계량 단위의 동일 요금 근거는 같아야 한다. effort에서 가격을 추론하지 않는다. 할인·세금·구독·우선처리의 가격 수집 엔진이나 개별 실시간 호출 비용 계산이 아니다.
- 공급사 계량·Hub 추정·미상/누락을 구분한다. 분모0·비용0·미보완 미상/환산·단가·정규화 근거 미비는 확정 불가다. 추정 보완은 원 미상 자료와 사유를 보존하며0으로 숨기지 않는다.

### 6-2. 영향 테이블 · 저장 범위

물리명 미정. 선택 미확정 월의 산정 구성·기준 실적/단가 스냅샷·관리자 보완 근거 전체가 하나의 저장/확정 범위다. 실적 원장·모델 등록·다른 월을 이 화면에서 수정하지 않는다. SCR-021은 확정 기준 식별값·당시 결과만 참조하고 대상 월 수동 환산율/보정률을 한 번 적용한다.

### 6-3. 상태 전이·확정 보호

수동 작성/실적 초안 → 검증·보완 → 관리자 확정. 확정 월/이미 월 배정에 사용한 기준은 변경하지 않는다. 지연 계량은 원 사용 월 실적에 정정하되 과거 기준/배정은 고치지 않고 이후 초안에서 사용한다. 월말 승계 확정과의 경합·응답 유실은 현재 기준본/원 명령 결과로 검사한다. 최근3개월 자동 보정 제안은 제거하며 기본1.0·수동 보정만 SCR-021에 남긴다.

SCR-052는 월별 원 화면의 읽기 전용 이력을 상속한다. 독립 이력 목업·관리 화면 이력 탭을 복제하지 않는다.

## 7. API

기존 공통 조회/저장/명령·스냅샷 보존 계약의 소유 상세 설계 후속이다. 새 API 경로·와이어 속성·가격/계량 자동 수집 수단을 확정하지 않는다.

## 8. 엑셀

현재 표시 열·선택 월·반출 권한을 적용한다. 확정 기록은 당시 값으로 내보내며 미상/추정·근거 기준 시각을 감추지 않는다.
