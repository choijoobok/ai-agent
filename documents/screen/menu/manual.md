# 메뉴 관리

> 왼쪽에 보이는 **메뉴의 구조를 정리합니다** — 폴더를 만들고, 순서와 위치를 바꾸고, 아이콘을 정하고, 메뉴를 켜고 끕니다.

**메뉴 위치** 시스템 › 메뉴 › 메뉴 관리

[메뉴 관리 화면 — 트리를 직접 고치고 아래에서 그 메뉴의 관계를 봅니다](./mockup.html#main)

---

## 1. 먼저 알아 둘 것

- **고치면 그 자리에서 저장됩니다.** `[저장]` 버튼이 없습니다 — 칸을 고치거나 스위치를 누르거나 끌어다 놓으면 **바로 반영**됩니다.
- **되돌리기가 없습니다.** 칸은 다시 고치면 되고 스위치는 다시 누르면 됩니다. 다만 **끌어서 옮기는 것은 놓기 전에 물어봅니다** — 원래 자리를 기억하는 사람은 없기 때문입니다.
- **화면(맨 아래 단계)은 여기서 만들 수 없습니다.** 정확히 말하면 만들 수는 있지만 **열리지 않습니다** — 실제 화면은 개발이 배포해야 생깁니다. 여기서 자주 하는 일은 **폴더 만들기 · 순서 바꾸기 · 아이콘 · 켜고 끄기**입니다.
- **메뉴 이름은 여기서 못 고칩니다.** [다국어 메시지 관리]에서 고칩니다.
- **화면에 `menu.무엇` 같은 글자가 보이면** 그 메뉴의 이름이 아직 없는 것입니다.

---

## 2. 찾기

**들어오면 바로 전체가 나옵니다.** 조회 버튼을 누를 필요가 없습니다.

- 메뉴가 많으면 **트리 위의 검색 칸**에 넣으십시오. **이름 · 메뉴코드 · 화면 주소를 한꺼번에** 찾습니다.
- **거르지 않고 찾아갑니다** — 일치하는 곳이 강조되고 그 경로가 펼쳐지며 첫 번째로 화면이 이동합니다. (거르면 상위 폴더가 사라져 트리가 아니게 됩니다.)
- 전체를 접거나 펼치려면 `[모두 접기]` · `[모두 펼치기]`.
- `[조회]` 를 누르면 다시 읽으면서 **선택이 풀립니다.**

**목록의 숫자 세 칸**

| 칸 | 무엇을 세나 |
|---|---|
| `API 수` | 이 메뉴가 쓰는 기능 수 |
| `사용자 수` | **지금 이 메뉴에 닿을 수 있는 사람 수.** 폴더는 `—` 입니다 |
| `역할 수` | 이 메뉴에 권한을 주는 역할 수 |

## 3. 하기

### 3-1. 폴더 만들기

1. `[최상위 추가]` 또는 폴더를 고르고 `[하위 추가]`.
2. **메뉴 코드**를 넣고 확인합니다. 코드는 30자까지입니다.
3. 만들어진 줄이 **맨 아래에 생기고 자동으로 선택됩니다.**
4. 필요하면 **아이콘**을 고릅니다.
5. **이름은 [다국어 메시지 관리]에서** 채웁니다 — 그전까지는 코드 같은 글자가 보입니다.

[메뉴 추가 창은 코드 한 칸뿐입니다](./mockup.html#add)

**`[하위 추가]` 가 눌리지 않는 이유 셋**

| 왜 | 어떻게 |
|---|---|
| 아무것도 고르지 않았습니다 | 폴더를 고릅니다 |
| **고른 것이 화면입니다** | 화면 아래에는 메뉴를 둘 수 없습니다 |
| **5단계까지입니다** | 더 아래에는 만들 수 없습니다 |

### 3-2. 화면 연결하기

`화면 주소` 칸을 **두 번 누르면 고를 수 있는 목록**이 열립니다.

- **직접 입력할 수 없습니다.** 오타 하나가 곧 *열리지 않는 메뉴* 가 되기 때문입니다.
- **다른 메뉴가 이미 쓰는 주소는 목록에 없습니다.**
- 맨 위의 *(없음)* 을 고르면 **다시 폴더가 됩니다.**
- **하위가 있는 메뉴는 이 칸이 잠깁니다** — 화면과 하위 메뉴는 **둘 중 하나만** 가질 수 있습니다.
- **주황색 `미연결` 표시**가 붙으면 그 주소에 **실제 화면이 없다**는 뜻입니다. 눌러도 열리지 않습니다 — 개발 담당자에게 전달하십시오.
- **주황색 `고아` 표시**는 그 메뉴 자체가 **배포에서 없어졌다**는 뜻입니다. 자동으로 지우지 않는 이유는 **거기 걸린 권한이 사람이 준 것**이기 때문입니다 — 지울지는 사람이 판단합니다.

### 3-3. 순서와 위치 바꾸기 — 끌어다 놓기

줄을 끌어서 원하는 자리에 놓습니다. **놓으면 물어봅니다.**

- 확인 창이 **지금 자리**와 **옮길 자리**를 **나란히** 보여 줍니다 — 취소하고 원래대로 돌아갈 수 있도록.
- **기본은 취소**입니다. 실수로 엔터를 눌러 옮겨지지 않게 했습니다.
- **놓을 수 없는 자리에는 아예 놓아지지 않습니다** — 자기 자신이나 자기 아래로, 화면 아래로, 5단계를 넘는 자리.
- **다른 사람이 그 사이에 트리를 바꿨으면 거부됩니다.** 다시 조회하고 옮기십시오.

### 3-4. 메뉴 켜고 끄기

`사용` 스위치를 누르면 **무엇이 바뀌는지 알려 주고 물어봅니다.**

| 방향 | 무엇을 알려 주나 |
|---|---|
| **끌 때** | 함께 꺼지는 **하위 메뉴 수**와 **지금 이 메뉴에 닿을 수 있던 인원** |
| **켤 때** | 함께 켜지는 하위 수와 **그중 따로 꺼 두었던 수** |

> **켜는 쪽에도 경고가 있습니다.** 켜면 **개별로 꺼 두었던 하위까지 함께 켜지기** 때문입니다 — 이전에 무엇이 꺼져 있었는지는 기억하지 않습니다.

- **꺼진 메뉴는 이름이 흐리게** 보입니다.
- **꺼진 메뉴는 권한이 있어도 열리지 않습니다.** 권한 문제와 헷갈리기 쉬우니 먼저 여기를 확인하십시오.
- 취소하면 스위치가 **제자리로 돌아갑니다.**

### 3-5. 메뉴 지우기

줄을 고르고 `[삭제]`. **확인의 기본도 취소**입니다.

**네 가지가 남아 있으면 지울 수 없습니다.**

| 무엇이 | 어떻게 정리하나 |
|---|---|
| 하위 메뉴 | 먼저 옮기거나 지웁니다 |
| 쓰는 기능(API) | 개발 담당자에게 전달합니다 |
| 권한을 주는 역할 | [역할별 권한]에서 뺍니다 |
| 개인 예외 권한 | [개인 예외 권한]에서 지웁니다 |

- 버튼에 마우스를 올리면 **무엇이 막고 있는지** 알려 줍니다.
- **즐겨찾기는 함께 지워집니다** — 개인의 편의이지 운영 결정이 아니기 때문입니다.
- **대개는 지우지 말고 끄는 것이 맞습니다.**

### 3-6. 아래쪽 탭 셋

줄을 고르면 아래가 채워집니다. **셋 다 보기만 합니다.**

[아래 탭 셋 — 무엇을 쓰는가 · 누가 닿는가 · 누가 줬는가](./mockup.html#tabs)

| 탭 | 무엇을 답하나 |
|---|---|
| **사용 API** | 이 메뉴가 **무엇을 쓰는가** |
| **접근 가능 사용자** | **누가 닿는가** — 역할로든 개인 예외로든 |
| **권한 역할** | **누가 줬는가** — 어느 역할이 어떤 권한을 주는가 |

- 탭은 **열 때 조회**되고, 한 번 연 탭은 **다른 메뉴를 고를 때까지** 다시 읽지 않습니다.
- 여기서는 고칠 수 없습니다 — 고치는 곳은 [역할별 권한]과 [개인 예외 권한]입니다.

### 3-7. 엑셀로 받기

- `[⤓]` — 트리를 표로 펴서 내보냅니다.
- 엑셀 올리기는 이 화면에 없습니다.

## 4. 안 될 때

| 이런 일이 생기면 | 이유 | 어떻게 하나 |
|---|---|---|
| *트리가 변경되었습니다. 다시 불러오세요* | **다른 사람이 그 사이에 트리를 바꿨습니다** | `[조회]` 를 누르고 다시 합니다 |
| *자기 자신이나 하위 메뉴 아래로 옮길 수 없습니다* | 순환이 생깁니다 | 다른 자리에 놓습니다 |
| *메뉴 깊이 상한을 넘습니다* | 5단계까지입니다 | 상위 단계에 놓습니다 |
| *하위 메뉴가 있는 메뉴는 화면을 가질 수 없습니다* | 화면과 하위는 둘 중 하나입니다 | 하위를 먼저 옮깁니다 |
| *화면이 있는 메뉴에는 하위를 둘 수 없습니다* | 마찬가지입니다 | 화면 연결을 *(없음)* 으로 바꾸고 폴더로 만듭니다 |
| *권한이 부여된 메뉴는 화면을 비울 수 없습니다* | 그 메뉴에 권한이 걸려 있습니다 | 권한을 먼저 정리합니다 |
| *이미 있는 메뉴 코드입니다.* | 같은 코드가 있습니다 | 다른 코드를 씁니다. **다른 사람이 방금 만들었을 수도 있습니다** |
| *다른 곳에서 쓰고 있어 삭제할 수 없습니다.* | 3-5 의 넷 중 하나가 남아 있습니다 | 버튼에 마우스를 올려 무엇인지 확인합니다 |
| *없는 메뉴입니다.* | 다른 사람이 먼저 지웠습니다 | `[조회]` 를 누릅니다 |
| **메뉴 이름 대신 이상한 글자가 보입니다** | 그 메뉴의 이름이 비어 있습니다 | [다국어 메시지 관리]에서 채웁니다 |
| **주황색 `미연결` 이 붙어 있습니다** | 연결한 주소에 실제 화면이 없습니다 | 개발 담당자에게 전달합니다 |
| **주황색 `고아` 가 붙어 있습니다** | 그 메뉴가 배포에서 없어졌습니다 | 권한을 정리한 뒤 지우거나, 그대로 두어도 됩니다 |
| 화면 주소 칸이 안 열립니다 | 하위 메뉴가 있습니다 | 하위를 먼저 정리합니다 |
| 권한을 줬는데 메뉴가 안 보인다고 합니다 | **메뉴가 꺼져 있을 수 있습니다** | `사용` 을 확인합니다 |
| 고쳤는데 취소하고 싶습니다 | **되돌리기가 없습니다** | 다시 고칩니다. 옮긴 것은 다시 옮깁니다 |

## 5. 다른 메뉴와의 관계

**먼저 해야 하는 것**

| 무엇을 | 어디서 | 왜 |
|---|---|---|
| **화면 만들기** | **개발(배포)** | 여기서 주소를 골라도 실제 화면이 없으면 열리지 않습니다 |
| 메뉴 이름 넣기 | **[다국어 메시지 관리]** | 여기서는 이름을 못 고칩니다 |

**여기서 저장하면 바뀌는 곳**

| 어디가 | 어떻게 |
|---|---|
| **모든 사용자의 왼쪽 메뉴** | 순서·위치·아이콘·표시 여부가 바뀝니다 |
| **권한이 있어도 못 여는 메뉴** | `사용` 을 끄면 **권한과 무관하게** 닫힙니다 |
| [역할별 권한] · [개인 예외 권한]의 트리 | 같은 구조를 보여 줍니다 |
| 즐겨찾기 | 메뉴를 지우면 **함께 지워집니다** |

**같이 보는 화면**

| 무엇을 하려면 | 어디로 |
|---|---|
| 메뉴 이름을 고치려면 | **[다국어 메시지 관리]** |
| 권한을 주려면 | **[역할별 권한]** · **[개인 예외 권한]** |
| **여기로 들어오는 길** | **[API 카탈로그]** 아래 목록의 메뉴 줄을 두 번 누릅니다 |
| 왜 권한 오류가 나는지 | **[에러 로그]** → [API 카탈로그] → 여기 |

## 6. 자주 묻는 것

- **새 화면을 만들고 싶습니다** — 화면 자체는 개발이 만들어 배포해야 합니다. 배포된 뒤 여기서 **주소를 골라 트리에 붙입니다.**
- **저장 버튼이 없습니다** — 고치는 즉시 저장됩니다. 그래서 옮기는 것만 미리 물어봅니다.
- **메뉴 순서를 여러 개 한꺼번에 바꾸고 싶습니다** — 하나씩 끌어다 놓습니다. 한 번 놓을 때마다 그 폴더의 순서가 저장됩니다.
- **끈 메뉴를 다시 켜면 원래대로 돌아가나요** — 하위가 **전부** 켜집니다. 따로 꺼 두었던 것이 있으면 **다시 꺼야 합니다.**
- **`고아` 를 그냥 두어도 되나요** — 됩니다. 눌러도 열리지 않을 뿐입니다. 정리하려면 권한을 먼저 빼고 지우십시오.
- **5단계보다 깊게 만들고 싶습니다** — 할 수 없습니다. 화면 왼쪽에 그만큼 들어가지 않기 때문입니다.
