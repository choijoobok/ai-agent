# 역할 관리

> **역할을 만들고, 이름을 고치고, 끄고, 지웁니다.** 그 역할을 **누가 가지고 있는지**도 여기서 봅니다.

**메뉴 위치** 시스템 › 권한 › 역할 관리

[역할 관리 화면 — 위는 역할 목록, 아래는 그 역할을 가진 사람들](./mockup.html#main)

---

## 1. 먼저 알아 둘 것

- **권한 설정은 세 화면으로 나뉩니다.**

| 무엇을 | 어디서 |
|---|---|
| 역할을 **만든다** | **이 화면** |
| 그 역할에 **권한을 붙인다** | [역할별 권한] |
| 사람에게 **역할을 준다** | [사용자 관리]의 [보유 역할] 탭 |

- **역할 ID 는 나중에 바꿀 수 없습니다.** 고치려면 지우고 다시 만들어야 하는데, 쓰이고 있는 역할은 지울 수 없으므로 **사실상 한 번 정하면 끝**입니다.
- **끄는 것은 지우는 것보다 강력합니다.** `사용`을 끄면 **그 역할이 주던 권한이 전부 없어집니다.**
- **여기서는 권한을 볼 수 없습니다.** 어떤 권한을 주는지는 [역할별 권한]에서 봅니다.

---

## 2. 찾기

1. `역할명`에 조각을 넣거나 비워 두고 `[조회]`.
2. 목록에서 **한 줄을 고르면** 아래에 그 역할을 가진 사람이 나옵니다.

- **처음부터 꺼진 역할도 함께 나옵니다.** 감춰 두면 **같은 역할을 또 만들게 되고**, 그때는 저장이 실패합니다.
- 역할 ID 로는 조회할 수 없습니다 — 목록이 많지 않으니 **컬럼 제목의 필터**를 쓰십시오.

**목록의 숫자 세 칸**

| 칸 | 무엇을 세나 |
|---|---|
| `보유 인원` | 이 역할을 **받은 적 있는** 사람 수. **기간이 지난 부여도 셉니다** |
| `유효 인원` | 그중 **지금 실제로 유효한** 사람 수 |
| `권한 수` | 이 역할에 붙어 있는 권한 수 |

- **`—` 로 보이면 아직 저장하지 않은 새 줄**입니다. 0 과 다릅니다.
- 이 세 칸은 정렬되지 않습니다.

---

## 3. 하기

### 3-1. 역할 만들기

1. `[행 추가]` → `역할 ID` 와 `역할명`을 채웁니다.
2. `[저장]`.

- **`사용`은 켜진 채로 만들어집니다.** 만든 직후에는 가진 사람도 권한도 없으니 켜 두어도 아무 영향이 없습니다.
- **저장하기 전에는 아래가 잠깁니다.** 아직 아무도 못 가진 역할이니 볼 것이 없습니다.
- 다음 순서: [역할별 권한]에서 권한을 붙이고, [사용자 관리]에서 사람에게 줍니다.

### 3-2. 이름·설명 고치기

칸을 두 번 눌러 고치고 `[저장]`. **역할 ID 는 열리지 않습니다.**

### 3-3. 역할 끄기 — **가장 조심해야 하는 일**

`사용`을 끄고 `[저장]` 하면, 저장 전에 **세 가지를 알려 줍니다.**

[역할을 끄면 확인이 세 줄로 나옵니다](./mockup.html#disable)

| 무엇을 알려 주나 |
|---|
| 이 역할을 가진 사람이 **몇 명**이고 권한이 **몇 개**인지 |
| 그중 **아무 권한도 남지 않게 되는 사람이 몇 명**인지 |
| **그 사람들의 이름과 아이디** |

- **아무 권한도 남지 않는 사람은 다음 로그인부터 아예 못 들어옵니다.** 로그인 화면에서 막힙니다.
- 다른 역할을 가지고 있거나 [개인 예외 권한]이 있는 사람은 **막히지 않습니다** — 그래서 이름 목록에 나오지 않습니다.
- **기간이 지났거나 아직 시작 안 된 부여는 세지 않습니다.** 그 사람들은 지금 이 역할에서 아무것도 받고 있지 않습니다.
- 사람이 아주 많으면 *일부만 확인했다* 고 알려 줍니다 — **0명이라고 단정하지 않습니다.**
- **켜는 쪽에는 경고가 없습니다.** 권한이 늘어나는 것은 되돌릴 수 있기 때문입니다.

> **이미 접속 중인 사람은 그 자리에서 끊깁니다.** 역할을 끄면 영향을 받는 사람들의 접속이 무효가 됩니다.

### 3-4. 역할 지우기

**`보유 인원` 과 `권한 수` 가 둘 다 0 이어야 지울 수 있습니다.** 아니면 체크박스가 꺼지고, 마우스를 올리면 몇 건이 남았는지 알려 줍니다.

- **`유효 인원`이 0 이어도 `보유 인원`이 0 이 아니면 못 지웁니다.** 기간이 지난 부여도 기록으로 남아 있기 때문입니다.
- 지우려면 순서가 이렇습니다.
  1. [사용자 관리]에서 그 역할을 가진 사람들에게서 **부여를 지웁니다.**
  2. [역할별 권한]에서 그 역할의 **권한을 모두 뺍니다.**
  3. 여기서 지웁니다.
- **대개는 지우지 말고 끄는 것이 맞습니다.** 지우면 누가 언제 그 역할이었는지가 사라집니다.

### 3-5. 아래쪽 — 이 역할을 가진 사람

| 칸 | 무엇을 말하나 |
|---|---|
| `계정 사용 가능` | 계정이 켜져 있고 사용 기간 안인지. **잠김·휴면은 보지 않습니다** — 스스로 풀립니다 |
| `부여 상태` | *예정* · *유효* · *만료* |
| `부여 기간` | 언제부터 언제까지 |
| `개인 예외 보유` | 역할과 별개로 직접 받은 권한이 있는지 |
| `다른 역할 보유` | 이 역할 말고 다른 역할이 있는지 |

- **여기서는 보기만 합니다.** 부여를 고치는 곳은 [사용자 관리]의 [보유 역할] 탭입니다.
- 뒤의 두 칸이 **역할을 껐을 때 누가 막히는지**를 판단하는 근거입니다 — 둘 다 *없음* 인 사람이 막힙니다.
- 기간이 지난 부여도 목록에 보입니다. **다시 유효해질 수 있기 때문**입니다.

### 3-6. 엑셀

이 화면에는 **엑셀이 없습니다.**

## 4. 안 될 때

| 이런 일이 생기면 | 이유 | 어떻게 하나 |
|---|---|---|
| *이미 있는 역할 ID 입니다.* | 같은 ID 가 이미 있습니다. **꺼 둔 역할도 남아 있습니다** | `사용 여부`를 비우고 조회해 확인합니다 |
| 같은 ID 가 두 번 있다는 표시 | 지금 저장하려는 줄 안에 같은 ID 가 둘입니다 | 한 줄을 지웁니다 |
| *역할명은 필수입니다.* | 이름이 비었습니다 | 채웁니다 |
| *보유 사용자나 권한이 있어 삭제할 수 없습니다.* | 아직 쓰이고 있습니다 | 3-4 의 순서를 따르거나, **끄는 것으로 대신합니다** |
| *없는 역할입니다.* | 다른 사람이 먼저 지웠습니다 | 다시 조회합니다 |
| 삭제 체크박스가 꺼져 있습니다 | 보유자나 권한이 남아 있습니다 | 마우스를 올리면 몇 건인지 알려 줍니다 |
| `역할 ID` 칸이 편집되지 않습니다 | 저장된 줄의 ID 는 바꿀 수 없습니다 | 새로 만들고 옛것을 끕니다 |
| **아래 그리드가 비어 있습니다** | 역할을 고르지 않았거나, 아직 저장하지 않은 새 줄입니다 | 먼저 저장하고 그 줄을 다시 고릅니다 |
| 역할을 껐더니 사람들이 못 들어옵니다 | **예고한 대로입니다** | 다시 켜면 됩니다. 다만 **접속은 다시 해야 합니다** |
| 권한을 줬는데 아무것도 안 열립니다 | **역할 자체가 꺼져 있습니다** | 이 화면에서 `사용`을 켭니다 |

## 5. 다른 메뉴와의 관계

**먼저 해야 하는 것**

- 없습니다. 역할 만들기가 권한 설정의 **첫 단계**입니다.

**여기서 저장하면 바뀌는 곳**

| 어디가 | 어떻게 |
|---|---|
| **그 역할을 가진 사람들의 권한** | `사용`을 끄면 그 역할이 주던 권한이 전부 빠집니다 |
| **그 사람들의 접속** | 영향을 받으면 **그 자리에서 끊깁니다.** 다시 로그인해야 합니다 |
| [사용자 관리]의 역할 후보 | 여기서 만든 역할이 후보로 나옵니다. **꺼진 역할도 후보에는 나옵니다** |
| [역할별 권한]의 역할 목록 | 마찬가지입니다 |

**같이 보는 화면**

| 무엇을 하려면 | 어디로 |
|---|---|
| 이 역할이 **무슨 권한**을 주는지 | **[역할별 권한]** |
| 사람에게 역할을 **주거나 거두려면** | **[사용자 관리]** 의 [보유 역할] 탭 |
| 한 사람에게만 예외로 권한을 주려면 | **[개인 예외 권한]** |
| 어떤 사람이 지금 무엇을 할 수 있는지 | **[사용자 관리]** 의 [유효 권한] 탭 |

---

## 6. 자주 묻는 것

- **역할 ID 를 잘못 지었습니다** — 바꿀 수 없습니다. 새로 만들고 사람들의 부여를 옮긴 뒤 옛것을 끄십시오.
- **`유효 인원`이 0인데 왜 못 지우나요** — 기간이 지난 부여가 남아 있기 때문입니다. `보유 인원`을 보십시오.
- **끈 역할을 다시 켜면 권한이 돌아오나요** — 돌아옵니다. 다만 그 사람들은 **다시 로그인해야** 합니다.
- **역할을 지우면 누가 가졌었는지 남나요** — 남지 않습니다. 그래서 대개는 **끄는 것**이 맞습니다.
- **역할을 몇 개까지 만들 수 있나요** — 제한은 없습니다. 다만 사람이 관리할 수 있는 수를 넘지 않는 것이 좋습니다.
