# Overlay — 창 (실행 인자 · 참조 · 배열 · 장문)

**트리거**: 화면이 창을 띄운다.
**필수가 되는 절**: §1 모달 · §4-4 팝업 선택 결과 매핑.

> **등록/수정 모달은 이 템플릿에 없다.** 같은 표에 저장 경로가 둘이 되는 그 모양을 그리드
> 표준이 없앴다 — **행은 그리드 안에서 고친다.** 요청이 그 모양이면 **먼저 알린다.**

## 어느 창인가 — 넷뿐이다

| 무엇을 받나 | 창 | 요건서에 적을 것 |
|---|---|---|
| **API 호출의 인자** | 실행 파라미터 모달 | 칸 이름 · 타입 · 필수 · 기본값 |
| **다른 표에서 골라 여러 칸을 채운다** | 참조 팝업 | **후보의 출처**와 **채워지는 칸 전부** |
| 한 칸에 항목을 쌓는다 | 배열 편집 모달 | 후보 출처 · 개수 상한 |
| 한 칸에 긴 글 | 장문 편집 모달 | 글자 수 상한 |

## 참조 팝업 — 반드시 묻는 다섯

1. **후보를 어디서 가져오나** — 마스터 표인가, 기존 데이터에서 뽑나.
2. **고르면 어느 칸들이 채워지나** — **전부 적는다.** 하나라도 빠지면 *아이디와 이름이
   어긋난 행* 이 저장된다.
3. **비우면 어떻게 되나** — 짝이 되는 칸도 함께 비워야 한다.
4. **어느 칸이 창을 여나** — 값을 담는 칸과 여는 칸이 갈리면 사용자는 **보이지 않는 칸을
   고치는** 셈이 된다.
5. **후보 창에 검색이 필요한가** — 몇 개 안 되면 붙이지 않는다. 붙이면 *고르러 왔는데
   먼저 찾아야* 하는 창이 된다.

## 실행 파라미터 모달 — 반드시 묻는 셋

1. **칸마다 필수인가**, 기본값은 무엇인가. *흔한 쪽* 이 채워져 있어야 한다.
2. **대상 건수를 보여주나** — 대상이 화면과 무관한 실행이면 **보여주지 않는다**
   (*0건에 실행합니다* 가 된다).
3. **확인 창을 따로 두나** — **두지 않는다.** 이 모달이 확인을 겸한다.

## 흔한 누락

| 빠뜨린 것 | 일어나는 일 |
|---|---|
| **채워지는 칸의 목록** | 이름만 바뀌고 키는 옛 값으로 남는다 |
| **후보 조회의 인가** | 팝업의 조회는 **부르는 화면의 것**이다 — 그 화면이 선언하지 않으면 **403** |
| **후보 창에서 새로 만들 수 있나** | 마스터가 없으면 못 만든다 — *왜 추가가 안 되나* 가 남는다 |
| **취소와 오류의 구분** | 취소를 오류로 다루면 **취소마다 에러 창이 뜬다** |

## 적지 않는 것

창 크기 · 버튼 이름 · 호스트를 어디에 거나 — **전부 표준이다.**
