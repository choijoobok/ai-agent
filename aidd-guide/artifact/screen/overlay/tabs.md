# Overlay — 탭 (하단 디테일 · 화면 전체)

**트리거**: 자식 표가 둘 이상이거나, 화면 전체가 탭으로 갈린다.
**필수가 되는 절**: §1 화면 구성 · §1-1 연동 · §5 버튼(탭마다 갈리면).

## 먼저 — **둘은 다른 물건이다**

| | 하단 디테일 탭 | 화면 안 최상단 탭 |
|---|---|---|
| 무엇이 갈리나 | 한 화면 안의 **부분**(같은 부모의 여러 얼굴) | **화면 전체** |
| 전환할 때 | **묻지 않는다** — 표시가 바뀔 뿐이다 | **묻는다** — 미저장이 있으면 |
| 조회조건 | 마스터의 것 하나 | **탭 안에** 둔다 |
| 실물 | ⑤ `mdtabs` | ⑥ `excel` |

**요건서에 어느 쪽인지 적지 않으면 구현이 고르게 된다.**

## 반드시 묻는 것

1. **탭마다 무엇을 보여주나** — 표 이름과 부모와의 관계.
2. **탭을 열 때 조회하나** — 처음 열 때만인가, 옮길 때마다인가.
3. **한 탭의 저장이 다른 탭의 답을 바꾸나** — 바꾸면 저장 뒤 상대를 다시 읽어야 한다.
   **바꾸지 않는데 다시 읽으면** 사용자가 한쪽을 저장할 때마다 반대쪽이 조용히 재조회된다.
4. **저장 단위** — 탭마다 따로인가.
5. **대상이 없을 때** — 탭을 잠그나, **탭은 살리고 버튼만 잠그나**.
6. (최상단 탭) **탭마다 권한이 다른가** — 저장만 있는 탭은 `S` 가 없으면 **항목 자체가
   없어야 한다**.

## 흔한 누락

| 빠뜨린 것 | 일어나는 일 |
|---|---|
| **부모가 바뀔 때 안 연 탭** | 안 연 탭은 **조회로 갈아 끼워지지도 않는다** — 옛 부모의 데이터가 그대로 남는다 |
| **미저장 경고를 몇 번 묻나** | 탭마다 물으면 사용자가 **같은 물음에 두 번 답하면서도 무엇을 잃는지는 모른다** |
| **빈 상태 문구가 둘인 것** | *부모를 고르세요* 와 *자식이 없습니다* 는 **다른 사실**이다 |
| **탭을 잠갔을 때의 오해** | *이 부모에는 그 탭이 없나* 로 읽힌다 — 없는 것은 **고를 부모**다 |

## 적지 않는 것

탭바 높이 · 판의 최소 폭 · 개인화 키 · 접힘 — **전부 표준이다.**
