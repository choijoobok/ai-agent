# Overlay — 엑셀 (내려받기 · 올려받기)

**트리거**: 엑셀로 내려받거나 올려받는다.
**필수가 되는 절**: §0(`EXPORT_YN`) · §5 버튼 · §6-1 검증(올려받기면).

## 1. 내려받기 — **아무것도 안 적으면 표준이 처리한다**

화면이 그리는 표가 곧 내려받을 표면 **요건서에 적을 것이 없다**(프론트가 만든다).

**적어야 하는 것은 그렇지 않을 때다.**

| 묻는다 | 답이 없으면 |
|---|---|
| **파일의 표가 화면의 표와 같은가** | 다르면 서버가 만들어야 하는데, 구현이 그것을 모른 채 화면의 표를 내린다 |
| 다르다면 **무엇이 다른가** | 부모-자식을 조인해 한 장인가, 컬럼이 다른가 |
| **드롭다운에 항목을 더하나** | *조회로는 낼 수 없는 표* 가 있나(예: 자식이 하나도 없는 부모들) |
| 그 항목이 **가공을 하나** | 계산을 돌려 내리면 권한이 `EXPORT` 가 아니라 `EXECUTE` 다 |
| **`EXPORT_YN`** | 프론트 생성만 쓰면 서버 경로가 없어 **메뉴가 선언하지 않으면 아무도 그 권한을 못 갖는다** |

> **`EXPORT_YN` 이 이 Overlay 의 가장 흔한 누락이다.** 화면은 잘 도는데 **엑셀 버튼이
> 아무에게도 안 보인다.**

### 끄는 층이 둘이다 — **메뉴 단위와 그리드 단위**

| 끄는 것 | 무엇 | 언제 |
|---|---|---|
| `EXPORT_YN = 'N'` | **메뉴 전체** — 이 화면에서 내려받을 수 없다 | 화면에 엑셀이 아예 없다 |
| **`excel={false}`** | **그리드 하나** | 한 화면의 표 둘 중 **하나만** 막아야 한다 |

**마스터-디테일이면 한 메뉴에 그리드가 둘이므로 `EXPORT_YN` 으로는 하나만 막을 수
없다.** 그것이 둘째가 있는 이유 전부다.

> **쓸 자리는 좁다.** 개인정보처럼 *화면으로 보는 것은 되지만 파일로 나가면 안 되는*
> 표에만 쓴다. **마스터에 딸린 목록이라는 것은 끄는 이유가 아니다** — 2026-09-05 에
> `CODE_MGMT` 요건서가 그 이유로 *하단에 ②가 없다* 를 적었다가 지웠다.

**요건서에 *없어야 한다* 를 적기 전에 끄는 수단이 있는지 먼저 본다.** 그리드 크롬이
스스로 세우는 버튼은 화면이 선언한 것이 아니라서, 수단 없이 적으면 **구현이 이룰 수 없는
케이스**가 된다(템플릿 §5 의 `출처` 칸).

### 적지 않는 것

*현재 페이지* · *전체* 두 항목 · 상한 · 다운로드 이력 — **전부 표준이다.**

## 2. 올려받기 — **업로드가 아니라 읽기다**

파일은 서버에 올라가지 않는다. 브라우저가 읽어 **그리드에 붓고**, 저장은 **업무 탭과 같은
경로**다. 그래서 **업로드 엔드포인트를 요건서에 적지 않는다** — 없다.

| 반드시 묻는다 | 왜 |
|---|---|
| **대조 키** | 기존 행과 무엇으로 맞추나. 이것이 없으면 **신규/변경을 가를 수 없다** |
| **양식 컬럼** | 업무 탭과 **같아야 한다** — 갈리면 *방금 내려받은 파일을 업로드가 거절한다* |
| **행 상한** | 넘으면 **통째로 거절한다** — 조용히 자르지 않는다 |
| **판 전체를 봐야 아는 검증** | 파일 안의 중복 같은 것. §6-1 에 적는다 |
| **삭제를 어떻게 하나** | 파일에서 줄을 지운 것과 *지워라* 를 구별할 방법이 없다 — **삭제는 업무 탭의 일**이다 |
| **탭 권한** | 업로드 탭의 액션이 저장뿐이면 `S` 없는 사람에게는 **탭이 아예 없어야 한다** |

### 흔한 누락

| 빠뜨린 것 | 일어나는 일 |
|---|---|
| **대조 키** | 412행이 전부 신규로 잡혀 **감사 컬럼이 통째로 갱신된다** |
| **양식 그리드의 개인화** | 사용자가 컬럼을 숨기면 **그 상태로 다운로드되고 업로드가 거절한다** |
| **키에 여러 컬럼이 들어갈 때** | 구분자를 잘못 잡으면 **다른 두 행이 하나로 대조된다** |
| **최상단 탭 전환 경고** | 읽어들인 412행을 **남겨 둔 채 다른 일을 한다** |

## 3. 화면 유형이 바뀔 수 있다

올려받기가 있으면 대개 **화면 안 최상단 탭**이 함께 온다 → [tabs.md](./tabs.md) 를 켠다.
