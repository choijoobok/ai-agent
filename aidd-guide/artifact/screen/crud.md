# 단일 그리드 CRUD — **대화의 실물**

> **가장 흔한 요청이다.** [screen.md](./screen.md) 의 일곱 단계를 이 요청 하나에 실제로
> 적용해 보인다 — 절차가 아니라 **주고받는 말**이 여기 있다.

## 0. 요청

> **"`SMPL_ORDER` 로 주문 조회·등록 화면 하나 만들어줘."**

이 한 줄로는 §0 메타를 채울 수 없다. **묻는 것이 먼저다.**

## 1. 첫 답 — 확인한 것과 물을 것을 함께 낸다

```
확인했습니다:
  · SMPL_ORDER — 컬럼 26개, 상태 컬럼 ORD_STAT_CD(코드그룹 SMPL_ORD_STAT), LOCK_YN 있음
  · 자식 표 SMPL_ORDER_ITEM 이 있습니다 — 이 화면에서 다루나요?
  · 비슷한 화면: /sample/single-offset (단일 그리드 · 오프셋 · 컬럼 30)

정해 주셔야 하는 것 넷:
  1. 페이지 경로 — /order 로 할까요?
  2. 그릴 컬럼 — 26개 전부인가요, 아니면 목록에 낼 것만인가요?
  3. 액션 — R·S 만인가요? 엑셀(E)·확정 같은 실행(X)이 있나요?
  4. 페이징 — 총 건수를 보여줘야 하나요(offset), 대용량 이력인가요(cursor)?
```

- **확인한 것을 먼저 쓴다.** 질문만 다섯 개 던지면 사용자는 *이 사람이 표를 보긴 했나* 를
  먼저 의심한다.
- **자식 표의 존재를 알린다.** 요청자가 모를 수 있고, 알면 화면 유형이 바뀐다.
- **비슷한 화면을 댄다.** 요건서가 짧아지는 가장 빠른 길이다.

## 2. 답을 받으면 — 표를 먼저 채운다

> **"경로 `/order`, 컬럼은 목록에 낼 것만, R·S·E, offset. 품목은 다음 화면."**

이제 §0 이 채워진다.

| 항목 | 값 |
|---|---|
| 페이지 경로 | `/order` |
| 메뉴코드 | `ORDER_MGMT` 🤖 |
| 화면 유형 | 단일 그리드 |
| 처리 유형 | CRUD |
| 쓰는 액션 | R · S · E — `EXPORT_YN` = Y 🤖 |
| 페이징 | offset |

**메뉴코드를 보완했으면 🤖 를 붙인다** — 이름 규칙은 조직마다 다르다.

## 3. 컬럼 표 — 여기가 요건서의 중심이다

*목록에 낼 것만* 이라는 답은 **어느 것인지 정하지 않았다.** 후보를 내고 고르게 한다.

```
목록 컬럼을 이렇게 제안합니다 — 빼거나 더할 것을 알려주세요.

  ORD_NO(주문번호·PK) · ORD_NM · CUST_NM · ORD_STAT_CD · ORD_DT
  · ORD_QTY · UNIT_AMT · ORD_AMT(파생) · USE_YN + 감사 넷

  ORD_AMT·VAT_AMT 는 서버 계산으로 보입니다 — 화면에서 고치나요, 읽기 전용인가요?
  LOCK_YN 은 잠긴 행의 편집을 막는 용도로 보입니다 — 맞나요?
```

**파생과 잠금은 반드시 묻는다.** 이 둘을 잘못 잡으면 **화면이 금액을 스스로 정하거나
잠긴 행이 스스로 잠금을 푸는** 요청이 성립한다.

## 4. Overlay 를 태운다

이 화면은 조회조건이 있고 엑셀이 있다 →
[search-condition](./overlay/search-condition.md) · [excel](./overlay/excel.md).
상태 컬럼이 있으므로 요건서 **§6-3 상태 전이가 필수**가 된다.

## 5. 미결을 §9 에 모은다

```
## 9. 미결 · 확인 필요

| # | 무엇 | 정해지지 않으면 |
|---|---|---|
| 1 | ORD_NO 채번 규칙 — 서버가 정하나, 사용자가 입력하나 | 신규 행의 기본값을 정할 수 없다 |
| 2 | 삭제 허용 여부 — 품목이 있는 주문도 지울 수 있나 | 삭제 컬럼의 게이트를 정할 수 없다 |
| 3 | 메시지 키 접두 — order.* 로 시작하나 | 시드 생성 대상이 정해지지 않는다 |
```

**정해지지 않으면 무엇이 막히는지를 함께 쓴다.** 그래야 사용자가 **우선순위를 정할 수 있다.**

## 6. 승인 뒤

[playbook/crud-screen.md](../../playbook/crud-screen.md) 로 넘어간다.
**요건서에 없는 판단이 구현에서 필요해지면 요건서를 고치고 알린다** — 조용히 정하지 않는다.

## 이 대화에서 하지 않은 것

| 하지 않았다 | 왜 |
|---|---|
| 컬럼명을 만들어 냈다 | 표를 **읽고** 골랐다 |
| 컴포넌트·훅 이름을 적었다 | **어떻게** 는 요건서의 것이 아니다 |
| 그리드 크롬·페이징·감사 넷을 적었다 | **이미 표준**이다 |
| 질문을 한 개씩 나눠 던졌다 | 문맥 복원 비용이 사용자에게 간다 |
| 승인 전에 파일을 만들었다 | CLAUDE.md §6.3 |
