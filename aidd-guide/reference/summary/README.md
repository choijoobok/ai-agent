## 템플릿

## 품질 원칙 (필수)

1. **원문 인용** 섹션: 완전한 사실만. 의역·첨언 금지. URL 앵커 포함.
2. **프레임워크·용어** 섹션: 원문에서 직접 추출한 개념만. 저자의 워딩 유지.
3. **우리 프로젝트 반영** 섹션: AI 해석 허용 — 명시적 "해석" 표기 필수.
4. **구분 실패 시 해당 요약 폐기 재작성.**
