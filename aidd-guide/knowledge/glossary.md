# 용어 사전 — 이 저장소가 쓰는 말

> **같은 말을 다르게 쓰지 않기 위한 목록이다.** 여기 없는 말을 새로 만들기 전에
> **이미 있는 말이 그 뜻인지** 확인한다.
>
> 정의의 **원본은 소스**다 — 어긋나면 소스가 이긴다.

## 1. 인가

| 말 | 뜻 |
|---|---|
| **계층** | API 경로의 첫 마디 — `public`(비인증) · `common`(인증만) · `service`(인가). **그 밖은 전부 403** |
| **액션** | `READ` · `SAVE` · `EXPORT` · `EXECUTE` **넷**. API 경로의 **접두가 정한다** |
| **인가 사실** | (주체 × 메뉴 × 액션). 코드에 선언이 없고 **데이터**다 |
| **합집합** | 역할 여럿 + 개인 예외를 **더한다**. 우선순위도 거부도 없다 |
| **개인 예외** | 한 사람에게만 주는 권한. **기간 필수 · 사유 필수** — 마찰이 있어야 한다 |
| **고아**(메뉴) | 선언에서 사라졌지만 행이 남은 메뉴. `SRC_CD='ORPHAN'` — **지우는 것은 화면의 일** |

## 2. 데이터의 모양

| 말 | 뜻 |
|---|---|
| **감사 넷** | `REG_ID` · `REG_DTM` · `MOD_ID` · `MOD_DTM`. **사람이 쓰는 표에만** 둔다 |
| **주체 / 행위자** | *누구의 것인가* / *누가 했는가*. 둘이 갈리는 표는 `SYS_USER_PWD_HIST` 하나다 |
| **Y/N 플래그** | `CHAR(1)` + `YnConverter`. 컬럼 이름은 `*_YN` |
| **기간** | `VALID_FROM_DT` · `VALID_TO_DT`. **양끝 포함이고 `NULL` 이 제한 없음** |
| **메시지 키** | 점 표기 문자열. `SYS_MENU.MENU_NM` 과 `SYS_CODE.DTL_NM` 은 **이름이 아니라 이것** |
| **시드** | 배포가 넣는 데이터. **생성물**(선언에서 만든다)과 **사람 소유**(changeset 을 더한다)로 갈린다 |
| **changeset** | Liquibase 의 변경 단위. **이미 적재된 것은 고치지 않는다**(checksum) |

## 3. 조회

| 말 | 뜻 |
|---|---|
| **봉투** | 조회 요청의 몸통 — `{ conditions, sorts, page, params }` |
| **`conditions`** | **사용자가 좁힌 것**(조회조건 폼) |
| **`params`** | **구조가 정한 것**(부모 키 등). 사용자가 만든 것이 아니다 |
| **연산자 13종** | `eq` `ne` `in` `startsWith` `contains` `endsWith` `between` `gt` `gte` `lt` `lte` `isNull` `isNotNull` |
| **화이트리스트**(`*Spec`) | 조회조건이 걸 수 있는 필드의 목록. **선언되지 않은 필드는 400** |
| **페이징 모드** | `offset`(총 건수 있음) · `cursor`(없음) · `all`. **모드는 엔드포인트가 정한다** |
| **투영** | 응답 행이 싣는 컬럼 집합. **투영이 다르면 엔드포인트를 나눈다** |

## 4. 화면

| 말 | 뜻 |
|---|---|
| **행 상태** | `C`(신규) · `U`(변경) · `D`(삭제) · `null`(그대로). **`null` 인 행은 나가지 않는다** |
| **마스터 / 디테일** | 부모 그리드 / 자식 그리드. **저장 단위가 각각이다** |
| **디테일 탭** | 화면 **하단**의 탭. 전환할 때 **묻지 않는다** |
| **최상단 탭** | 화면 **전체**를 갈아 끼우는 탭(`ScreenTabs`). 전환할 때 **묻는다** |
| **크롬** | 그리드 제목줄·버튼·푸터 — 모든 그리드가 같은 자리에 같은 것을 둔다 |
| **컨트롤** | 화면 고유 버튼·셀렉트. `beforeRead`(좌) · `beforeTools`(우) |
| **실행** | 조회도 저장도 아닌 API 호출(`api.actions`). `EXECUTE` 인 경우가 많다 |
| **진행률** | 오래 걸리는 실행이 `jobId` 를 즉시 주고 화면이 폴링한다. `progress: true` |
| **참조 팝업** | 다른 표에서 **골라 여러 칸을 함께 채우는** 창 |
| **양식**(엑셀) | 업로드가 받아들이는 컬럼 배열. **개인화를 열지 않는다** |
| **개인화** | 사람의 속성(서버) — 컬럼 **너비**는 기기의 속성이라 `localStorage` |
| **시그니처** | 화면의 컬럼 목록을 나타내는 값. 바뀌면 저장된 그리드 설정을 **버린다** |

## 5. 운영

| 말 | 뜻 |
|---|---|
| **유령**(배치) | `END_DTM` 이 NULL 인 채 오래 남은 실행 이력 = 비정상 종료. **락 만료 안전망이 정리한다** |
| **창고**(배치) | 같은 `BEAN_ID` 를 갖는 등록 여럿. **`BATCH_ID` 가 락 키라 서로 다른 락을 잡는다** |
| **쿨다운** | 작업이 끝나도 다시 못 잡는 시각(`RELEASE_DTM`). **회수 시한(`EXPIRE_DTM`)과 다른 축** |
| **보존 / 만료 청소** | *일어난 일* 을 기간 뒤에 지운다 / *지금 도는 것* 이 끝나서 지운다 |
| **오버라이드** | `SYS_CONFIG` 의 행. **행의 존재가 곧 `변경됨`** |

## 6. 이 저장소의 말버릇

| 표현 | 뜻 |
|---|---|
| **"기계가 막는다"** | 어기면 빌드가 깨진다(ESLint · ArchUnit · 훅 · 시드 검증) |
| **"사람이 지킨다"** | 검사가 없다 — 리뷰와 문서가 유일한 방어선 |
| **"실물"** | 저장소에 실제로 있는 코드. **실물 없는 규칙을 쓰지 않는다** |
| **"영원히 초록인 게이트"** | 통과하지만 아무것도 검사하지 않는 테스트 — **없는 것보다 나쁘다** |
| **"조용히"** | 오류 없이 잘못된 결과가 나오는 것. 이 저장소가 가장 경계하는 실패 방식 |
| **"축이 다르다"** | 두 값이 서로 다른 질문에 답한다 — **한 컬럼으로 합칠 수 없다** |
