# ADR-0001. 단일 저장소 + 프론트엔드 임베드 빌드

- 상태: 채택
- 일자: 2026-08-22

## 맥락
백엔드(Spring Boot)와 프론트엔드(React)를 어떻게 배치하고 배포할 것인가.

## 결정
단일 Git 저장소에 `sources/backend/`, `sources/frontend/` 를 두고, 프론트 빌드 산출물을
Spring Boot `resources/static` 에 복사해 **단일 실행 JAR** 로 배포한다.

## 근거
- 사내 백오피스는 배포 단위가 하나인 편이 운영이 단순하다.
- 동일 오리진이 되어 CORS 가 사라지고 세션 쿠키 인증이 자연스럽다.
- API 변경과 화면 변경이 한 커밋/한 PR 에 묶여 정합성이 유지된다.

## 대안
| 대안 | 기각 사유 |
|---|---|
| 저장소 분리 + 별도 배포 | 버전 정합성 관리 비용, CORS·쿠키 설정 부담 |
| Nginx 정적 서빙 + 백엔드 분리 | 인프라 구성요소 추가. 사내망 백오피스에 과함 |

## 결과
- 프론트만 고쳐도 전체 재배포가 필요하다. → 개발 중에는 Vite dev 서버로 대응.
- SPA 라우팅 새로고침 대응을 서버에서 처리해야 한다 ([25-build-and-deploy](../../standard/build-deploy.md) §3).
